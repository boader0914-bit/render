# Bundled fonts

SABUN의 기존 회사 홈페이지에서 사용하는 글꼴을 STAYDATALAB 화면에서도 자체 제공한다. 글꼴 바이너리는 수정하지 않았다.

| 파일 | 저작권 및 라이선스 | 공식 출처 |
| --- | --- | --- |
| `MaruBuri-Regular.otf` | NAVER Corporation · SIL Open Font License 1.1 | [네이버 한글한글 아름답게](https://hangeul.naver.com/font), [저작권 안내 및 라이선스 전문](https://help.naver.com/service/30016/contents/18088?osType=PC&lang=ko) |
| `Pretendard-Regular.otf`, `Pretendard-Bold.otf` | Kil Hyung-jin 및 원저작자 · SIL Open Font License 1.1 | [Pretendard 공식 저장소](https://github.com/orioncactus/pretendard), [LICENSE](https://github.com/orioncactus/pretendard/blob/main/LICENSE) |

- 확인일: 2026-09-20.
- `MaruBuri-LICENSE.txt`는 네이버 공식 고객센터의 저작권 안내와 영문·국문 라이선스 전문이다. 웹페이지 태그와 표시용 공백만 제거했다. 네이버는 마루 부리에 같은 규정이 적용되며 영문 원문에 법적 효력이 있다고 안내한다.
- `Pretendard-LICENSE.txt`는 공식 저장소의 [원문 LICENSE](https://raw.githubusercontent.com/orioncactus/pretendard/main/LICENSE)를 그대로 저장했다. 파생 원글꼴의 저작권 고지도 포함한다.
- 재배포할 때 해당 저작권 안내와 라이선스 전문을 함께 유지한다. 글꼴 자체 판매, 수정본의 예약 글꼴명 사용 등은 각 전문의 조건을 따른다.
