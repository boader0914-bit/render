구글플레이 Data Safety 입력용 정리

시행일 2026.07.08 · 운영자 사분

기본 답변

  • 사용자 데이터 수집 여부: 예
  • 개인정보처리방침 URL: /privacy
  • 계정 및 데이터 삭제 요청 URL: /account-delete
  • 전송 중 암호화: 예. 운영 URL은 HTTPS로 제공합니다.
  • 데이터 공유: 판매 또는 광고 목적 공유 없음. 서버 호스팅, API 연동, 장애·보안 대응 등 서비스 운영에 필요한 처리만 사용합니다.
  • 독립 보안 심사: 현재 미해당. 심사 또는 인증을 받은 뒤에만 예로 변경합니다.

수집 데이터 유형

  • 개인 정보: 아이디, 이메일, 연락처, 선택 입력한 숙소 또는 회사명
  • 앱 활동: 검색 키워드, 검색 기간, 순위 범위, 검색 이력, 리포트 열람·재사용 기록
  • 기기 또는 기타 식별자: 세션 식별값, IP 해시, 브라우저 식별값 해시
  • 사용자 콘텐츠: 관심숙소 등록 정보, 숙소명, 객실수, 객실종류, 요일별 가격, 시설 정보
  • 위치 정보: 기기 위치는 수집하지 않습니다. 사용자가 입력한 지역명과 검색 키워드만 분석 기준으로 사용합니다.
  • 결제 정보: 현재 앱 내부 결제 정보는 수집하지 않습니다. 유료 결제 기능 추가 시 별도 갱신해야 합니다.

사용 목적

  • 앱 기능: 로그인, 회원 식별, 리포트 생성, 검색 이력 재사용, 관심숙소 비교
  • 분석: 지역 경쟁 리포트 품질 개선, 검색 속도 개선, 오류 재현
  • 보안·부정 이용 방지: 로그인 실패 제한, 검색 요청 제한, 세션 보호
  • 고객 지원: 계정·데이터 삭제 요청, 문의 대응, 처리 상태 안내

제출 전 확인

  • 광고 SDK, 결제 SDK, 푸시 알림, 앱 분석 SDK를 추가하면 해당 SDK의 수집 항목을 다시 반영해야 합니다.
  • Play Console Data Safety는 앱의 모든 배포 버전 기준으로 작성해야 하므로 TWA 패키징 전후에 최종 점검합니다.
  • 이 페이지는 운영 초안입니다. 실제 제출 전 법무·정책 검토로 최종 문구를 확정합니다.
