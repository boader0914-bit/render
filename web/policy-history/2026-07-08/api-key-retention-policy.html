API 키 보관

네이버 데이터랩, 검색광고 API 키는 운영 서버의 설정 저장소에 보관합니다. 키 입력 화면은 관리자 권한으로 제한되며 화면에는 민감값을 마스킹해 표시합니다.

고객 데이터 보관

  • 고객 데이터: 회원 계정, 검색 이력, 관심숙소, 동의 이력
  • 업체 기준 데이터: 관리자 보정 업체정보, 객실 수, 가격 기준, 채널 정보
  • 수집 이력: 수집 실행 이력, 저장된 트렌드, 관측 기록

접근 통제

관리자 계정과 B2B 계정은 권한이 분리됩니다. 저장 자료, 원본 파일, 관리자 보정값, API 키 설정은 관리자 권한에서만 접근하도록 제한합니다.
