운영자 관리 콘솔

업체 마스터, 관심도 수집/검수, 데이터 신뢰도, 내부 품질관리를 한 흐름으로 관리합니다.

운영 흐름 수집 결과를 업체 ID로 묶고, 관심도와 검수값을 보강한 뒤, 신뢰도 기준으로 사업자 리포트를 보호합니다.

내부 품질관리(SLA v1.0)는 잠금 상태이며 상태 확인, 승인/반려, rollback 가능한 항목만 다룹니다.

DB 상태를 불러오는 중입니다.
01 업체 DB 마스터·검수값 업체 ID, 대표명, 업종, 지역, 채널 URL, B2B 노출을 정리 02 관심도 수집/검수 검색·SNS 신호 네이버 트렌드, 검색광고, SNS 언급량, 수집 큐를 관리 03 데이터 신뢰도 수집값과 검수값 분리 자동 관측, 관리자 확정값, 변경 이력, 신뢰도 등급을 확인 04 내부 품질관리 SLA v1.0 잠금 승인/반려, rollback, 상태 확인만 유지
01 업체 DB 수집 결과를 고유 업체 ID와 검수 가능한 마스터 정보로 정리합니다.

검색 후 업체를 선택하면 자동 관측값, 관리자 검수값, 수정 이력, 전략 산식 검수 상태를 한 곳에서 확인합니다.

왼쪽 업체를 선택하면 자동 관측값과 관리자 검수값을 분리해 확인하고 수정할 수 있습니다.
02 관심도 수집/검수 지역 키워드와 내 숙소 키워드의 검색·SNS 신호를 수집 대기열과 검수값으로 관리합니다.

외부 API 연결 전에는 수동 입력과 관리자 검수값으로 보강하고, 사업자 화면에는 점수와 근거 요약만 노출합니다.

03 데이터 신뢰도 자동 수집값과 관리자 확정값을 분리해 업체별 신뢰도 기준을 올립니다.

업체 상세의 자동 관측값, 검수 프로필, 수정 이력, 전략 산식 검수 상태를 함께 보며 리포트 노출 기준을 판단합니다.

데이터 신뢰도 점검

company_id 중복 후보, 수집값/검수값 충돌, 신뢰도 등급 근거, 고유 ID 품질을 관리자 전용으로 확인합니다.
