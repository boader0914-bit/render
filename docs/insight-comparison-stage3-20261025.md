# 인사이트 3단계: 지역 배경과 홈 요약

2026-10-25 KST. 개발·로컬 검수 완료, 운영 배포 전. 이 단계에서 운영 수집·예약·보호 설정·원본·기존 발행본을 변경하지 않았다.

## 화면

- 홈: 선택한 내 매장, 현재 30일 예약률·수량·확인 금액, 선택 경쟁업체의 공통 날짜 차이, 내 지역 신호, 확인할 항목 최대 3개. 미등록·준비 중·확인 대기를 구별한다.
- 경쟁업체 차이는 같은 지역/타지역, 직접 경쟁/운영 참고, 업종 차이를 함께 표시한다. 지역 평균·성과 순위·인과 효과·자동 가격 제안을 생성하지 않는다.
- 지역분석: 내 매장·선택 경쟁업체·활성 관심지역을 공식 지역 번호로 묶는다. 같은 지역의 여러 업체는 한 번만 표시한다. 다른 지역은 참고 비교다.
- 본문 네 묶음: 수요 흐름(방문·체류·소비), 관심 흐름(검색), 수요 배경(인구·산업), 관광 구성(자원·다양성).
- 최근 마감월까지 저장된 최대 12개월을 조회하고, 지표마다 실제 최신 공표월·표시기간·확보 월수·공백을 표시한다. 공백은 선으로 연결하거나 0으로 채우지 않는다. 연간 통계는 연간으로 남긴다.
- 세부 월별 표와 근거는 기본 접기다. 기존 내 매장·관심지역 상세 분석은 펼치거나 명시적 지역 링크를 선택한 경우만 읽는다. 관심지역 관리 UI는 설정으로 이동했다.
- 기존 여섯 메뉴와 A/B/C 상세, 현재 30일 비교 계약을 유지한다. 선택 상태는 메뉴 이동·새로고침·뒤로가기에서 재사용한다.

## 별도 지역 요약 계약

중앙 GET `/api/insight/v1/regions/comparison-summary?ownId=...&month=YYYY-MM`을 추가했다. `ownId` 생략은 항상 `null`인 참고 조회이며 첫 내 매장을 자동 선택하는 기존 briefing과 구별한다. 명시한 내 매장은 등록 관계를 검증한다.

- `schemaVersion=1`, `mode=comparison_region_summary`, `source=datalab_saved`, `networkAttempted=false`.
- `bindings`: 선택 내 매장과 등록 경쟁업체의 원래 소재지·공식 집계 지역·등록 상태. `/me.comparisonRegionBindings`는 현재 허용된 모든 업체의 별도 경계를 제공한다.
- `groups`: 공식 지역·역할·연결 업체·저장 지표·부분/실패 사유. 일반구는 공식 계층이 확인된 경우에만 상위 시로 묶는다. 새 지역·미연결은 임의 기본값 없이 사유를 표시한다.
- `unresolved`: 업체·관심지역별 미연결 사유. 외부 오류 본문·인증 값·원본 상품 자료는 투영하지 않는다.
- `access`: `summaryOnly=true`, `fullAnalysis=false`, `preparation=false`. 경쟁업체 소재지 요약을 관심지역 한도나 기존 상세·갱신 권한에 합치지 않는다.
- 중앙은 읽기 전후 로그인·등록 관계·지역 연결을 재검증한다. BFF도 읽기 전과 저장 직전 최신 `/me`를 확인한다. 회원/지역/관계 변경, 취소된 응답과 저장은 차단한다.
- 정상 0, 일부 수량/금액, KOSIS 미수집·이전 자료·연결 필요·통계 비공개를 구별한다. 서로 다른 검색지수 산정기간을 직접 비교하지 않는다.

## 저장·재확인

신규 `comparison-region-read-cache.cjs`는 기존 전체 지역분석 캐시와 분리했다. 고객·조회 대상·선택 내 매장·등록 관계·공식 지역 연결을 키에 포함하며 저장 자료를 먼저 표시하고 뒤에서 확인한다.

- `INSIGHT_COMPARISON_REGION_CACHE_DIR` 또는 `DATA_DIR/insight-comparison-region-cache`. Render 기본 경로 `/var/data/insight-comparison-region-cache`.
- 영속 저장본은 재시작 후 인증된 bootstrap의 `comparisonRegionViews`로만 복원한다. bootstrap은 계산·외부 수집을 시작하지 않는다. 홈은 기존 저장 reportViews도 활용한다.
- 임시 연결 실패는 정상 저장본을 유지한다. 401/403/404/409로 경계가 바뀌면 관련 표시를 차단한다. 계정 전환·등록 해제·늦은 응답·디스크 저장 경합도 검증했다.
- 원본·발행본이 아닌 파생 표시 캐시다. 실행 중 기본 유효기간 30분, 재시작 보관 유효기간 최대 7일이며 반복 읽기로 확인 시각을 새로 만들지 않는다.
