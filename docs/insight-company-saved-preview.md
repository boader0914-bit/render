# 업체 월간 저장 자료 우선 표시

운영 연결 서버는 업체 자료를 읽을 때마다 중앙 `/me` 또는 관리자 고객 보기의
`/me`로 현재 로그인과 업체 등록 관계를 확인한다. 이 권한 확인은 캐시로 생략하지 않는다.

허용된 업체·숙박월의 정상 캐시가 없으면 중앙의
`/companies/:id/collection?month=YYYY-MM&savedOnly=1`을 최대 3초 동안 먼저 조회한다.
브라우저의 기존 `month` 요청 형식은 유지하고, 기본월은 연결 서버에서 한국시간의
현재 월로 지정한다. 저장 조회를 지원하지 않거나 자료가 없거나 연결에 실패하면
기존 전체 조회로 진행한다. `401`·`403`에는 저장 자료를 반환하거나 재시도하지 않는다.

저장 조회는 같은 업체·월의 `company-integrated-v4-product-max-room-reuse` 정상
월간 자료만 표시한다. `responseCache.state=preview`, `calculation.mode=saved_only`로
구분하고 최신 전체 조회는 뒤에서 한 번만 진행한다. 실제 0과 미관측·금액 미확인은
원래 값 그대로 유지한다. 조회 실패 시 저장된 정상 수치와 실패 안내를 유지한다.

이 임시 표시 자료는 메모리에만 두며 정상 영속 캐시나 일별 검수 보관본으로 승격하지
않는다. 전체 조회가 정상 완료되고 기존 검증을 통과한 자료만 영속 저장·검수 보관한다.
기존 정상 영속 캐시와 발행본은 유지한다.

다른 숙박월을 선택할 때 A 기본정보·상품과 B 예약채널은 같은 로그인·등록 업체의
기존 자료를 참고 표시한다. C 통합관측은 선택한 월의 저장 자료가 없으면 비우고
조회 중으로 표시한다. 이전 월의 예약·매출을 새 월 값으로 복사하지 않는다.
임시 참고 표시나 로그인 기본정보만으로 실제 월간 자료 표시 완료를 기록하지 않는다.

검증: `node --test customer-portal/test/*.test.cjs`. 별도 회귀 검증은
`company-saved-preview.test.cjs`에서 조회 시간 제한, 자료 범위, 권한 철회, 보관 금지,
실패 후 유지와 정상 완료 전환을 확인한다.

## 오래 걸리는 최신 확인

같은 업체·월의 유효한 저장 자료를 이미 확보한 경우에만 전체 최신 조회에 최대
10분의 별도 백그라운드 기한을 적용한다. 저장 자료가 없는 최초 전체 조회는 기존
180초, 로그인·권한 확인은 기존 20초, 저장 자료 선조회는 3초를 유지한다. 임시 조회나
일반 고객 입력으로 다른 경로의 기한을 늘리지 않는다.

이 백그라운드 업체 GET만 Node HTTP/HTTPS 전송을 사용하여 일반 fetch의 별도
헤더 대기 제한으로 먼저 끊기는 일을 방지한다. 전체 기한은 응답 헤더·본문에 함께
적용하며 JSON 본문은 최대 16MiB, 리다이렉트는 금지한다. 인증·접근 제한 결과와 기존
한정 재시도 규칙을 유지하고, 수집 명령·로그인·다른 일반 요청의 전송 방식은 바꾸지 않는다.

화면은 서버가 `refreshing=true`로 실제 진행을 알리는 동안 5초 → 10초 → 20초 →
30초 간격으로 자동 확인한다. 기존 24회 뒤에 조용히 멈추지 않으며, 완료하면 최신
검증 결과로 자동 전환한다. 페이지 이동·재진입에도 저장 자료를 먼저 표시한다.
실패 시 자동 확인을 멈추고 사유 안내와 다시 확인 버튼을 제공한다. 15분을 넘거나
64회에 도달하면 지연 상태를 명시하고 수동 재시도를 남긴다. 진행 중이라는 서버 응답
없이 영속 자료의 재검증 표시만 남은 경우에는 기존 24회의 확인 한도를 유지한다.

`background-json-get.test.cjs`는 헤더·본문 기한, 크기 제한, 리다이렉트 금지와 인증
실패 보존을 검증한다. `company-collection-cache.test.cjs`는 24회 이후 자동 완료,
진행 중 메뉴 이동·복귀, 실패·시간 초과와 미확인 값 보존을 확인한다.

최신 확인 중 로그인 확인 GET 등이 일시적인 `502`·`503`·`504` 또는 네트워크 오류로
실패한 경우, 같은 업체·월의 유효한 저장 자료가 있으면 제한적으로 자동 재확인한다.
마지막 정상 자료와 연결 지연·재시도 상태를 표시하며, 기존 증가 간격과 15분 전체
기한을 유지한다. 연속 세 번 실패하면 자동 확인을 멈추고 다시 확인 버튼을 남긴다.
정상 응답은 연속 실패 횟수를 초기화하지만 전체 대기 기한은 늘리지 않는다.
재확인마다 중앙 로그인·등록 관계를 새로 확인한다. `401`·`403`·`404`, 제한 응답,
잘못된 자료 형식과 영구 오류는 재시도하지 않는다. 페이지·업체·월 변경, 작성 중인
수정 양식과 저장 자료 유효기간을 검사하며, 재시도가 기한 지난 수치를 연장하지 않는다.
