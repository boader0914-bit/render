# 업체 월간 저장 자료 우선 표시

운영 연결 서버는 업체 자료를 읽을 때마다 중앙 `/me` 또는 관리자 고객 보기의
`/me`로 현재 로그인과 업체 등록 관계를 확인한다. 이 권한 확인은 캐시로 생략하지 않는다.

허용된 업체·숙박월의 정상 캐시가 없으면 중앙의
`/companies/:id/collection?month=YYYY-MM&savedOnly=1`을 최대 3초 동안 먼저 조회한다.
브라우저의 기존 `month` 요청 형식은 유지하고, 기본월은 연결 서버에서 한국시간의
현재 월로 지정한다. 저장 조회를 지원하지 않거나 자료가 없거나 연결에 실패하면
기존 전체 조회로 진행한다. `401`·`403`에는 저장 자료를 반환하거나 재시도하지 않는다.

저장 조회는 같은 업체·월의 `company-integrated-v4-product-max-room-reuse` 정상
월간 자료만 표시한다. `responseCache.state=preview`, `calculation.mode=saved_only`로
구분하고 최신 전체 조회는 뒤에서 한 번만 진행한다. 실제 0과 미관측·금액 미확인은
원래 값 그대로 유지한다. 조회 실패 시 저장된 정상 수치와 실패 안내를 유지한다.

이 임시 표시 자료는 메모리에만 두며 정상 영속 캐시나 일별 검수 보관본으로 승격하지
않는다. 전체 조회가 정상 완료되고 기존 검증을 통과한 자료만 영속 저장·검수 보관한다.
기존 정상 영속 캐시와 발행본은 유지한다.

다른 숙박월을 선택할 때 A 기본정보·상품과 B 예약채널은 같은 로그인·등록 업체의
기존 자료를 참고 표시한다. C 통합관측은 선택한 월의 저장 자료가 없으면 비우고
조회 중으로 표시한다. 이전 월의 예약·매출을 새 월 값으로 복사하지 않는다.
임시 참고 표시나 로그인 기본정보만으로 실제 월간 자료 표시 완료를 기록하지 않는다.

검증: `node --test customer-portal/test/*.test.cjs`. 별도 회귀 검증은
`company-saved-preview.test.cjs`에서 조회 시간 제한, 자료 범위, 권한 철회, 보관 금지,
실패 후 유지와 정상 완료 전환을 확인한다.
