실제 저장 응답 3개 지역을 사용한 로컬 전체 앱에서 수치·기준월·결과 ID 대조 **27/27**이 일치했고, 관련 회귀 검사 **87/87**이 통과했다. 아래 6개 표시 표본은 모두 2초 이내다. **운영 미배포**이며 현재 운영 기준 `e3edf2f95d1f`는 유지한다. 배포 후 실제 운영 화면·응답 시간을 확인하는 것이 바로 다음 작업이다.

## 변경 범위

- 기본 관광 카드는 기존의 별도 프로필 대신 공통 지역 저장 결과를 읽는다. 동일 계정·지역·요청월·13개월 조건의 동시 소비자는 같은 GET을 공유한다.
- 요청월과 지표의 최신 정상월을 구별한다. 요청 `2026-09`에서도 방문 지표의 정상월이 `2026-08`이면 그대로 표시한다. 지표별 월이 다르면 임의로 통일하지 않는다.
- 수치 확보와 원본 근거·지역 범위 확인을 구별한다. 수치가 있어도 근거가 부족하면 그 상태를 유지한다.
- 지역 전환·저장 결과 도착 시 카드 부분만 갱신한다. 입력 중인 검색어·커서·선택 지역을 보존한다.
- 표시 측정은 계정·지역·월·결과 ID에 더해 화면 진입 순번을 확인한다. 재진입 때 이전 측정값을 비우며 늦게 도착한 이전 순번의 완료 통지를 거절한다.

`web/regional-location-summary.js`의 공통 변환, `web/app.js`의 기본 카드 연결, `web/regional-analysis.js`의 공통 저장 상태·표시 측정 연결을 검수했다. 새 공급자 호출이나 무거운 과거 프로필 조회로 표시 문제를 우회하지 않는다.

## 로컬 전체 앱의 표시 시간

실제 저장 응답을 반환하는 로컬 HTTP에 300ms·1,200ms 지연을 넣었다. 사용자 지역 변경·이전 분석 이어보기 동작을 앱 이벤트 처리 전에 기록하고, 현재 지역 카드의 준비 상태·결과 ID를 DOM에서 확인한 뒤 두 애니메이션 프레임까지 측정했다. 앱의 내부 표시 시간만을 단독 근거로 사용하지 않았다.

| 동작·자료 경로 | 주입 지연 | 동작→카드 표시 |
| --- | ---: | ---: |
| 천안 전환·저장 GET | 300ms | 367.2ms |
| 사천 전환·저장 GET | 300ms | 383.7ms |
| 산청 이전 분석 이어보기·캐시 | 1,200ms 조건 | 38.4ms |
| 천안 전환·저장 GET | 1,200ms | 1,262.0ms |
| 사천 전환·저장 GET | 1,200ms | 1,269.8ms |
| 산청 재전환·캐시 | 1,200ms 조건 | 60.5ms |

캐시 표본은 저장값을 먼저 표시한 시간이며 후속 확인 GET의 완료 시간과 다르다. 요청 로그의 실제 저장 GET 응답은 300ms 조건에서 311.6~320.1ms, 1,200ms 조건에서 1,204.9~1,219.0ms였다. 이 시험은 **실제 자료를 쓴 로컬 표시 검수**이며 운영 네트워크·인증·동시 부하·재시작 직후의 2초 보장이 아니다.

재진입 최종 증빙에서는 같은 산청 결과라도 표시 순번이 1→2로 바뀌고, 이전 1,267ms를 재사용하지 않고 새 캐시 표시 32ms가 기록됐다. 이는 위 독립 계측 6개 표본과 구분되는 앱 측 재진입 회귀 확인이다.

## 회귀·화면·요청 검수

관련 회귀 87/87 통과: 공통 변환·기본 카드 연결·공통 저장 결과 UI·순번 격리와 기존 관련 경계. 재진입 시 기존 표시값 제거, 새 카드 반영 전 대기 상태, 이전 순번의 늦은 완료 거절, 현재 순번 완료 수용을 포함한다. 최종 JavaScript 문법 검사 3개와 공백 검사도 통과했다.

라이트·다크 화면을 확인했고, 카드가 놓인 실제 표면 대비 검사 표본은 라이트 71개·다크 25개, 최저 대비 4.73이었다. 산청 다크 카드와 사천 라이트 카드 화면을 별도로 저장했다. 이 결과를 앱 전체 화면의 접근성 검사 완료로 일반화하지 않는다.

여러 재진입·지연·미확보 시나리오를 합한 로그에는 지역 저장 GET 10회가 있다. **동일 조건의 동시 조회가 1개 GET을 공유한다는 의미이지 전체 검수가 1회 호출이었다는 뜻은 아니다.** 기본 관광 카드용 기존 `/api/tourism-data/location-history` 호출과 비GET 요청은 없었다. 외부 호출·수집·집계 재생성은 로컬 검수 서버에서 허용하지 않았다.

로컬 서버가 제공하지 않는 부가 `worker-schedule`·KOSIS 경로의 GET은 501로 기록됐다. 이번 공통 관광 카드 검수와 구별하며 해당 부가 기능의 운영 검수를 완료했다고 주장하지 않는다. 서버와 임시 브라우저 탭은 검수 후 종료했다.
