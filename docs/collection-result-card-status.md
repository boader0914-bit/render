# 수집 결과 카드의 수량·상태 표시

2026-10-13 개발 범위. 수집 결과 분석 카드와 연결 상세에서 핵심 수치를 먼저 표시하고, 긴 객실 구성 설명과 계산 기준은 접어둔다. 원본·객실 검수값·예약 추정·매출 합산 기준은 변경하지 않는다.

## 표시 원칙

- 숙박의 기간 누적 수량은 `객실`로 표시하되 `14일 예약 합계`처럼 집계기간을 함께 표시한다. 물리적인 객실 총량과 날짜별 수량 합계를 구분하며, 당일 이용 판매 단위는 기존 `회`를 유지한다.
- 글램핑·펜션 등 시설 구성 혼합은 `여러 시설·객실 유형 포함`으로 짧게 안내한다. 중복·총량 충돌·실제 조회 누락 경고를 이 안내로 대신하지 않는다.
- `일부 미확인`으로 여러 원인을 묶지 않는다. 실제 숙박 조회 일수, 빠진 날짜·상품, 수량 충돌과 데이유즈 보정 근거 부족을 각각 표시한다. 수집 실패를 정상 예약 0으로 바꾸지 않는다.
- 데이유즈 상태는 상품 존재 근거, 선택한 수집 범위, 실제 응답·누락 근거를 함께 사용한다. `requested`만으로 성공이라 판단하지 않는다. 구형 자료에 상태 근거가 없으면 미확인을 유지한다.
- 상품 없음이 확인되면 수량 카드는 생략하고 `데이유즈 없음`을 짧게 표시한다. 상품 유무만 확인한 경우는 `데이유즈 있음 · 예약 수량 미수집`, 숙박만 선택한 경우는 `데이유즈 수집 제외`, 실제 실패는 `예약 자료 미확보`로 구분한다. 정상 응답의 예약 0회는 0회로 표시한다.
- `수집 근거와 판매 흐름`은 기본 접힘을 유지한다. 펼치면 판매 흐름을 먼저 보여주며, 객실 총량부터 예약 비율 계산까지는 내부 `객실 수·예약 계산 기준`에 다시 접어둔다.
- 설명을 펼치거나 단위를 바꿔 표시해도 저장값·예약 비율·추정매출은 그대로다.
