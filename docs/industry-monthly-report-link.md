# 업종 집계와 월간 리포트 연결

## 연결 기준

- 업종분석에서 지역을 선택한 뒤 **월간 리포트에 연결**을 누르면 업종·실제 지역·숙박월·유효 관측 마감일을 전달한다. 전체 지역은 이 경로의 대상이 아니다.
- 기존 업체·키워드·지역 리포트에도 실제 선택 업체의 업종과 소재지에 해당하는 저장 집계를 참고 항목으로 연결한다. 검색어의 지명으로 소재지를 추측하지 않는다.
- 지역 리포트의 명시적 참고 업종은 조건을 변경하면 해제한다. 본문 지역 집계의 업종 필터로 오인하지 않도록 별도로 표시한다.
- 표본은 선택 월 중 키워드 검색 1~20위에 유효하게 관측된 업체의 합집합이다. 복합시설은 해당 업종마다 포함되므로 업종 간 합계를 더하지 않는다.

## 저장 결과 재사용

`industryAnalysisService.readSaved()`는 결과와 상태 파일만 읽는다. 초기화·집계·대기열 등록·자료 수집·외부 API 호출을 하지 않는다. 한 리포트에 여러 참고 조건이 있어도 원본 변경 감지는 한 번 공유한다.

리포트의 `snapshot.industryBenchmarks`에 조건·수치·저장 키·결과 버전·계산 버전·원본 버전·산출 시각·확보율·객실 검수 상태와 대기 사유를 보존한다. 마감월의 관측 기준은 월말 이내이며 원래 입력 기준일과 구별한다. 잘못된 조건, 손상된 수치, 버전 누락이나 미래 산출 시각은 유효 집계로 연결하지 않는다.

신규 미리보기는 기존 숙박 집계를 재사용하면서 최신 저장 참고 집계를 읽는다. 승인한 미리보기를 초안으로 저장하면 그 근거가 고정된다. 발행·조회·PDF 출력은 다시 업종 자료를 읽지 않는다. 이후 변경은 명시적으로 만든 수정본에서만 반영한다. 기존 발행 리포트에 참고 항목을 소급 삽입하지 않는다.

## 수치 해석과 상태

- 본문 예약률: 예약 수량 / 공급 수량.
- 업종 예약률: 날짜 안에서 업체별 예약률을 동일 비중 평균한 뒤 관측 날짜를 동일 비중 평균.
- 두 값의 계산 기준과 대상 업체가 다를 수 있으므로 같은 비율로 비교하거나 수량·매출을 더하지 않는다.
- 공개 예약과 타채널 추정 수량·매출은 구분한다. 관측된 0은 유지하고 자료 없음·오류·집계 대기를 0으로 바꾸지 않는다.
- 이전 정상 저장본은 수치를 보존하면서 갱신 필요·대기·실패 상태와 사유를 함께 표시한다. 저장 파일 손상은 집계가 아직 없는 경우와 구별한다.
- 비활성 지역 보정은 무시한다. 이전 지역 판정 정책의 집계는 저장 키를 유지한 채 `stale`로 표시한다. 업종 화면의 기존 준비 경로에서 갱신하며, 리포트 조회는 갱신을 시작하지 않는다. 마감월의 이전 정상 결과 보관 정책은 유지한다.
