# 지역지표 자료 확보·갱신 관리

2026-10-16 개발본. 운영 배포나 실제 제공기관 자료 갱신을 수행했다는 기록은 아니다.

## 화면과 기준

기존 **DB → 지역 DB → 지역 자료 갱신 관리**에 자료 확보 현황을 표시한다. 선택 지역과 기존 지역분석 메뉴는 유지한다. 관리 화면을 열거나 상태를 확인하는 행위는 외부 API 요청·정리 작업·예약을 만들지 않는다.

- 월간 관광·검색 지표: 각 지표의 최신 정상월, 그 월까지 최근 13개월 확보율, 조회 마감월의 실제 상태, 누락월과 안전한 사유를 표시한다.
- `13/13개월 확보`와 `조회 마감월 미확보`는 동시에 발생할 수 있다. 전자는 확보한 이력의 연속성이고 후자는 최신성이다. 최신월 차이를 곧바로 공급자 장애나 미발표로 단정하지 않는다.
- 인구·산업: 월간·연간 원래 기준기간과 확보 항목 수를 유지한다. 13개월 확보율이나 월간 전망의 관측 공백으로 계산하지 않는다.
- 정상 응답의 0은 확보한 관측값으로 인정한다. 부분 응답·오류·미확보·공표 대기를 0으로 바꾸지 않는다. 구버전 자료에 사유가 없으면 `사유 미기록`으로 표시한다.
- 자료 묶음이 일부 응답이어도 개별 지표의 명시적인 정상 응답과 값이 확인되면 그 지표는 보존한다. 정상 근거가 없거나 중복·충돌한 값은 확보 수에 넣지 않는다.
- 월별 상세는 접어 두고, 확인이 필요한 지표에서 필요한 월만 펼쳐 본다. 제공기관의 원문 오류·계정·인증키는 전달하지 않는다.

## 세 가지 시각을 구별

1. **원자료 확보 시각**은 저장된 관측자료의 확인 시각이다.
2. **지역 자료 관리 갱신 시도**는 이 관리 기능의 자료 준비 작업 시작·종료 기록이다. 외부 요청이 허용된 작업도 저장자료만 사용했을 수 있으므로 요청 있음·없음·미기록을 구별한다. 수요전망·기존 리포트 준비·개별 API에서 별도로 실행한 갱신 시도를 전부 통합한 감사 이력은 아니다.
3. **결과 정리 시각**은 파생 결과를 저장한 시각이다. 원자료의 최신 발표·갱신 성공을 뜻하지 않는다.

자동 갱신의 마지막 예정 시각(`policy.lastRunAt`)은 실제 시작·완료 시각으로 쓰지 않는다. 다음 예정 시각은 지역 자료 묶음 전체의 예약이며, 개별 지표의 발표일이나 지표별 독립 예약을 뜻하지 않는다.

## API와 저장

`GET /api/regional-analysis`의 기존 응답에 `management`를 추가한다. 이는 저장된 결과·작업·정책으로 만드는 읽기 전용 표시 자료다. 제공기관 파일의 전체 검사나 원자료 재계산은 수행하지 않는다.

작업 큐의 제한된 이력에서 같은 지역·이력 창의 자료 갱신 시도를 읽는다. 이후의 저장자료 정리 작업이나 월 변경이 앞선 갱신 실패를 가리지 않도록 분리한다. 기록이 없는 경우 성공이나 실패를 추정하지 않는다. 작업 처리 완료만으로 모든 지표의 갱신 성공을 판정하지 않는다.

이전 결과 파일은 변경하지 않는다. 값이 같아 결과번호를 재사용해도 새 갱신 시도 상태는 별도로 표시한다. 기존 갱신 버튼·예약·호출 예산·잠금을 재사용하며 자동 갱신을 임의로 켜거나 숙박 수집 설정을 변경하지 않는다.

## 검증과 다음 단계

`npm run test:regional-analysis`는 정상 0, 지연된 최신월, 공표 대기·오류·사유 미기록, 정적 통계, 갱신 실패 후 정상자료 보존, 재시작과 월 변경, 읽기 요청의 무작업성을 검사한다. 실제 로컬 앱 검증은 합성 제공기관만 사용하며 외부 통신을 금지한다.

다음 단계는 운영 배포 후 실제 지역별 저장자료와 관리 화면을 대조하는 것이다. 이후 저장 전망과 발표된 공식값을 비교하는 예측 검증을 연결한다. 과거 전망을 나중의 관측값으로 덮어쓰지 않는다.
