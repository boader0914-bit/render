# 네이버 통합검색 Place 광고 증거 계약

## 확인된 사실

- 2026-08-15 동일 디버깅 세션에서 `경남 글램핑` 네이버 통합검색 Place 영역에 `광고` 표식이 있는 업체 4개가 보였다.
- 확인된 순서는 `합천H글램핑(1000421329)`, `럭셔리 비토섬 제이글램핑(1995649140)`, `옥돌캠핑장(2092090019)`, `아르비토 호텔 글램핑(2000486899)`이다.
- 각 광고 링크는 `ader.naver.com`을 거치며 목적지 경로에 `/place/{numeric Place ID}`를 포함했다.
- 같은 디버깅 세션의 Render 기본 Place 수집은 HTTP 200과 유기 결과 50건을 얻었지만, 두 `adBusinesses` 후보 모두 `total=0`, `items=0`이었다.
- 따라서 현재 누락은 기존 `adBusinesses` 배열을 읽는 파서에서 발생한 것이 아니다. 화면 광고와 Render 숙박 목록 snapshot의 광고 원천 또는 요청 문맥이 다르다.

## 이번 변경의 범위

- 화면에서 보이는 정확한 `광고` 표식과 광고 목적지의 Place ID가 함께 있을 때만 광고 증거로 인정한다.
- 순서는 화면 관측 순서를 사용하고 Place ID로 중복을 제거한다.
- 산출물에는 순서, Place ID, 업체명, 증거 수준만 남긴다.
- 원문 HTML, 광고 추적 URL, 쿠키, 요청 헤더 및 Provider 원문은 저장하지 않는다.
- 현재 실화면에서 확인한 4건은 정제 fixture로만 보존한다.

## 현재 상태와 다음 경계

이 변경은 광고 식별 계약과 파서를 검증한다. 아직 Render Web이 네이버 통합검색의 실제 브라우저 DOM을 읽는 transport는 구현하지 않았으므로 라이브 광고 수집 완료가 아니다.

다음 단계에서는 한국 사용자 브라우저 문맥의 DOM을 안전하게 정제하는 수동 browser transport와, Render 서버 문맥에서 같은 광고가 관측 가능한지를 분리해 검증해야 한다. 기존 `/accommodation/list`는 유기 Place 목록 원천으로 유지하고 광고 결과의 근거로 사용하지 않는다.
