# 경남글램핑 객실 총량 교정 (2026-09-24)

대상 결과: `gyeongnam_manual_hfoclnpleienponiipmmajjf_glamping_20260924_163655`.
운영 저장 자료를 읽기 전용으로 대조했으며 네이버 재수집은 수행하지 않았다.

## 원인

기준 설명을 읽는 정규식이 `운영기준 미만 103개 오프라인/차단 추정`의
기간 누적 103개까지 객실 총량으로 잘못 해석했다.
이 값으로 계산된 `salesSignal.lodging.maxTotal`을 객실 재고의 관측 최대와 함께 사용했다.
그 결과가 이후 v4 `capacityBasis.observedMaximum`에 포함되어 다시 이력 기준으로 사용됐다.

운영 저장 원문: `전체객실수후보=19개(날짜별 총량 최대값, 19일 확인) · 운영기준 미만 103개 오프라인/차단 추정`.
토리글램핑의 과거 `stockBasis.lodgingMaxTotal`은 19이지만
`salesSignal.lodging.maxTotal`은 103이었다. 최신 결과의 실제 날짜별 재고 최대는
19였지만, 누적 기준으로 103이 전달되어 전화예약 및 매출 추정을 과대 계산했다.

## 확인한 교정 대상

| 업체 | 기존 표시 | 저장 재고에서 복원한 최대 |
|---|---:|---:|
| 시즌글램핑 | 28실 | 10실 |
| 월명 글램핑 | 27실 | 16실 |
| 피카푸 피크닉앤글램핑 진주점 | 147실 | 38실 |
| 더뷰인비토 글램핑 | 56실 | 29실 |
| 거제생각속의집펜션 | 14실 | 12실 |
| 럭셔리 토리글램핑 | 103실 | 19실 |

라파엘펜션&글램핑은 현재 재고 최대 44실이지만 과거 재고 최대 47실이 있어
임의로 40실 이하로 줄이지 않는다. 40실 초과는 검토 표시이며 상한이 아니다.
표의 값은 수집 기반 추정이다. 시즌글램핑의 10실은 사용자가 실제 수량으로 확인했다.
시즌글램핑은 지원되는 관리자 보정 API를 통해 10실을 저장했고 변경 이력을 확인했다.
가격과 객실별 가격 보정은 입력하지 않았다.

## 적용 원칙

- 활성 DB 보정값이 최우선이다.
- 수집마다 직접 확인된 `daily.rawTotal` 또는 `currentObservedMaximum`을 사용한다.
- 이전 기준값이 이미 더해진 `observedMaximum`을 직접 관측 근거로 재사용하지 않는다.
- 이전 버전은 보정 없는 재고 전용 `stockBasis.lodgingMaxTotal`만 복원 근거로 사용한다.
- 판매 집계값과 보정된 날짜 총량은 관측 최대 근거에서 제외한다.
- 설명 문구에서는 명시된 객실 기준 수량만 읽고 기간 누적 차단량은 제외한다.
- 원본 CSV, 상세 응답, 과거 스냅샷은 삭제하거나 덮어쓰지 않는다.
- 결과 및 업체 DB의 조회 계산에 같은 기준을 적용하여 예약·매출도 재계산한다.
