# KOSIS 인구·산업 통계 연결

지역 주민과 사업체의 구조를 보여주는 공식 자료다. 관광객 구성이나 숙소 실제 매출을 뜻하지 않으며, 사전 입력된 입지 점수·클러스터를 자동으로 수정하지 않는다.

## 인증과 운영

- 운영 웹서비스 `glamping-datalab-v2`의 환경변수 `KOSIS_API_KEY`만 사용한다.
- KOSIS 공유서비스에서 발급한 전용 키다. 공공데이터포털 공통 서비스키로 대체하지 않는다.
- 키는 관리자 화면·로컬 파일·로그·Git에 저장하거나 출력하지 않는다. 설정 조회는 존재 여부만 반환한다.
- 설정 → API·연동 → 인구·산업 통계에서 지역을 선택하고 **공식자료 갱신**을 누른다.
- 일반 화면 진입, 상태 조회, 저장자료 새로고침은 저장된 자료만 읽는다. 자동 예약 작업이나 네이버 숙소 수집과 연동하지 않는다.
- 현재 제공되는 최신 공표기간 하나씩 가져온다. 인구는 월별, 산업은 연도별이며 연간값을 월별로 나누지 않는다.
- 기본입지와 자료·출처 화면에서 각 통계의 기준기간·원자료 갱신일·조회시각·단위·공식출처를 표시한다.

## 통계표

모두 기관코드 `101`이며 표별 공식 분류 메타를 검증한다.

| 자료 | 통계표 | 항목 | 주기 |
| --- | --- | --- | --- |
| 주민등록 인구 | `DT_1B040A3` | `T20/T21/T22` 총·남·여 | 월 |
| 주민등록 세대수 | `DT_1B040B3` | `T1` | 월 |
| 5세별 주민등록 인구 | `DT_1B04005N` | `T2` 계, 연령 분류 | 월 |
| 사업체수 | `DT_1YL20832` | `T10` | 연 |
| 종사자수 | `DT_1YL15014` | `T001/T002/T003` 총·남·여 | 연 |
| 제조업 사업체수 | `DT_1YL5702` | `T10` | 연 |
| 제조업 종사자수 | `DT_1YL5802` | `T10` | 연 |

**세대수는 인구총조사의 가구수와 다르다.** 산업 자료는 등록기반 사업체·종사자 통계다. 제조업 규모를 숙박·워크숍 예약 수요로 해석하지 않는다.

## 지역과 품질 기준

지역원장 `web/data/region_master.json`의 활성 분석지역을 사용한다. KOSIS `getMeta&type=ITM`에서 각 통계표의 지역명과 상위 시도명을 함께 검증한다. 인구표와 산업표의 지역코드는 서로 다르므로 법정동·관광 코드 앞자리를 그대로 재사용하지 않는다. 동명지역·폐지지역 등으로 하나의 지역을 확인할 수 없으면 **지역코드 확인 필요**로 남긴다.

- 정상 숫자 `0`은 실제 0으로 저장한다.
- 결측·비공개 부호는 `null`과 별도 상태로 보존한다.
- 항목·지역·단위·주기·기준기간이 맞지 않으면 정상 자료로 반영하지 않는다.
- 실패·불완전 응답이 이전 정상 자료를 덮지 않는다. 이전 값이 표시되면 지난 자료임을 표시한다.
- 최초 부분 응답은 정상값·결측·비공개 상태를 함께 보존하되 정상 연결로 집계하지 않는다. 실패 상태와 갱신 대기시간도 재시작 후 유지한다.
- 파일은 `/var/data/history/kosis` 아래 저장하고 성공 시점별 보관 이력을 남긴다. 조회에 사용자 인증키를 포함한 URL을 기록하지 않는다.
- 각 표의 최종수정일은 `sourceUpdatedAt`, 실제 조회일은 `retrievedAt`/`updatedAt`이며 발표일과 동일하다고 단정하지 않는다.

## 관리자 API

| 경로 | 역할 |
| --- | --- |
| `GET /api/settings/kosis` | 키 존재 여부, 저장 지역 수, 지표 정의와 상태; 외부 호출 없음 |
| `GET /api/kosis/region?regionKey=kr_gyeonggi_pocheon` | 선택지역의 저장 자료만 조회 |
| `POST /api/settings/kosis/refresh` | JSON `{ "regionKey": "kr_gyeonggi_pocheon" }`, 선택지역 공식자료 갱신 |

세 경로 모두 관리자 전용이다. 갱신은 JSON·동일 출처를 확인하고 인증키·임의 endpoint·임의 통계표를 요청 본문으로 받지 않는다. 외부 요청은 KOSIS 고정 HTTPS 경로만 사용하며 리디렉션, 인증 오류와 호출 한도 응답에서 반복 요청하지 않는다. 같은 지역의 동시 갱신을 합치고 순차 호출·최소 간격·내부 일일 요청 예산을 적용한다. 내부 예산은 제공기관 잔여량과 다른 수치다.

기본값은 요청 시작 간격 최소 1초, 동시 요청 1개, 지역별 갱신 간격 5분, 한국시간 하루 100회이다. 지역 한 곳의 7종 자료를 처음 갱신하면 메타·자료 조회를 합쳐 최대 14회 요청한다. 연간 요청은 `prdSe=Y`이고 제공기관 응답의 `PRD_SE=A`를 내부 연간 주기 `Y`로 정규화한다.

## 검증

`npm run test:kosis`는 제공기관 응답을 모의 처리한다. 실제 키 검증이나 전국 자료 확보를 뜻하지 않는다. 운영 연결 완료 판정에는 사용자 키로 정상 값을 수신·저장한 뒤 동일 지역을 다시 읽어 지역·기간·단위를 확인해야 한다.
