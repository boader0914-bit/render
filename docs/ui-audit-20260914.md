# UI 점검 및 수정 기록 · 2026-09-14

## 결과와 범위

관리자·이용자 화면을 라이트/다크 모드에서 점검했다. 공통 색상 규칙과 과거 화면별 고정 색상이 충돌했고, 일부 모바일 폼·설명문은 고정 최소 너비 또는 줄바꿈 금지 때문에 잘렸다. 아래 확인된 문제를 `web/admin-theme.css`에서 수정했다. 테두리를 두껍게 만드는 방식은 사용하지 않았다.

- 작업 기준: `b6318e36c938e5472d9706af749458793b56a5ec`의 선택 지역 카드 정렬 변경 포함.
- 작업 브랜치: `codex/ui-audit-themes-20260914`.
- 운영 서버는 점검 시 `a9f0197ee6d6`을 응답했다. 이번 작업에서 운영 배포하지 않았다.
- 수집·계산·DB·계정 로직과 운영 자료는 변경하지 않았다.

## 재현 방법

운영 API에서 읽은 실제 저장 자료를 로컬 미리보기 서버에 제공했다. 샘플은 포천글램핑의 31일 수집 결과, 업체 마스터 198개·지역 45개, 수집 이력, 해핑글램핑 상세, 산청 관광 자료다. 로컬 서버는 운영 서버로 요청을 전달하지 않고 모든 API 쓰기 요청을 거부한다. 스냅샷은 Git에서 제외된 `tools/ui-audit/`에만 두었으며 저장소에는 포함하지 않는다.

화면 크기는 PC 1440×1000, 모바일 390×844를 사용했다. 태블릿 768px는 일부 화면을 추가 확인했다. 실제 렌더링의 색상·배경·가로 너비를 검사하고 문제 화면을 시각적으로 확인했다. 접힌 영역은 별도로 열어서 점검했다.

## 검사 해석과 남은 검증

이 기록은 모든 계정·자료·기기에서 오류가 없다는 인증이 아니다.

- 글자 대비 검사는 보이는 일반 DOM 텍스트와 계산된 단색 배경을 대상으로 했다. 일반 글자는 4.5:1, 큰 글자는 3:1을 기준으로 문제 후보를 찾았다. 그라데이션·이미지·SVG·가상 요소의 모든 픽셀을 검사한 것은 아니다.
- 네이버의 초록색 `N` 표시는 브랜드 마크로 분리했다. 옆의 `네이버` 링크 문구는 별도로 읽을 수 있다.
- 로그인·가입 페이지, 실제 수집 중/실패/재시도 상태, 회원·삭제요청이 가득 찬 목록, 관심숙소 등록 후 비교, 모든 연도·월의 관측자료 펼침은 이번 로컬 자료로 전부 검증하지 않았다.
- 실제 iPhone/Android의 설치형 앱, 글자 크기 확대, 소프트 키보드, Safari는 추가 확인이 필요하다.
- 현재 지역의 기본 선택, 지표 정의, 메뉴 명칭 등 기능·정보 구조는 이번 스타일 수정에서 변경하지 않았다.
