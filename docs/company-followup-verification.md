# 업체 월별 자료의 후속 자동 확인

`view=saved`는 마지막 정상 저장본을 먼저 표시한다. 일반 GET은 선택한 업체·월만 검증하며, 다른 월의 처리 완료를 기다리지 않는다. 선택월과 비교월의 계산 기준, 원본, 발행본은 유지한다.

변경 없는 저장월은 `runCheckpointRead`에서 제한된 검증만 수행한다. 긴 업종 집계와 업체 상세 읽기는 안전한 비동기 경계에서 잠시 멈췄다가 같은 작업을 이어간다. 이 경로는 원본 재구성, 색인 재생성, 수집, 다른 분석 작업 대기를 할 수 없다. 검증된 원본 색인과 현재 파일 상태·객실 검수값·저장월의 무결성·작업 세대·관측마감일이 모두 맞아야 정상 결과를 반환한다. 작은 검증 증명 파일만 원자적으로 갱신한다.

변경, 손상, 기한 초과, 취소, 저장 잠금 또는 미준비 상태는 캐시 적중으로 취급하지 않는다. 기존 직렬 검증과 재계산을 사용하고, 화면에는 이전 자료와 실제 진행/오류 상태를 유지한다. 새 계산 자체를 2초에 끝냈다고 표시하지 않는다.

운영 검수에서는 `appNavigationDisplayMs`(저장본 표시)와 `appNavigationLatestReadyMs`(일반 확인 결과의 실제 화면 표시)를 별도로 측정한다. 후자는 원래 업체·월·세션·자동 요청의 정상 응답이 실제 두 프레임 동안 표시됐을 때만 기록된다. `cachedReads`와 스케줄러의 `checkpointRead*` 수치는 적중·대기·실패를 진단하며, 자료의 내용이나 인증 값을 포함하지 않는다.

관련 회귀: `test_analytical_checkpoint_reads`, `test_company_integrated_cached_revision`, `test_company_integrated_read_db`, `test_company_detail_checkpoint_reads` 및 기존 업체·월별 원본/화면 회귀.
