# 수집 기록 접기

2026-10-13 개발. 수집 화면은 워커 카드와 현재 작업 진행을 먼저 보여주고, 지난 수집 기록은 기본으로 접는다.

- 헤더에는 조회된 최근 기록 수와 최근 종료 결과를 표시한다. 진행 중인 접수를 최근 완료 결과로 표현하지 않는다.
- 조회 범위는 즉시수집 최근 50건과 워커별 예약 최근 20회다. 전체 보관 자료의 총건수가 아니다. 검색 결과 수와 실제 표시되는 최대 50건은 펼친 본문에서 안내한다.
- 실패·중단, 일부 완료, 검토 필요 건수를 접힌 상태에서도 표시한다. 배지를 누르면 다른 검색 조건을 비우고 해당 상태의 기록을 펼친 뒤 상태 필터로 포커스를 옮긴다.
- 재수집 검토로 미실행된 기록은 실패와 구분한다. 저장 품질이 일부 완료인 결과는 완료 필터와 분리한다.
- 펼침 선택은 브라우저에 boolean만 저장한다. 메뉴 이동, 상태 새로고침, 페이지 재접속 후 선택을 유지한다. 저장소를 사용할 수 없으면 현재 페이지에서 선택을 유지하며 최초 상태는 접힘이다.
- 즉시수집 또는 예약 기록 조회 실패는 접힌 헤더에서도 알린다. HTTP 200 안의 예약 config:null도 확인 불가로 구분한다.
- 워커 진행 카드와 기존 상태 조회 주기는 유지한다. 접기와 필터 변경은 수집·예약·취소 요청을 보내지 않는다.
