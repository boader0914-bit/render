# 인사이트 비교 구조 1단계 구현·검수

2026-10-25 KST. 로컬 개발·검수 완료. 운영 배포 전.

## 구현 범위

- 중앙 `insight-comparison-v1`: 같은 지역/다른 지역/지역 미확인, 공통 업종/다른 업종/업종 미확인, 직접 경쟁/운영 참고를 각각 판정한다.
- 표시 가능, 수치 비교 가능, 행동 제안 가능을 구분한다. 같은 지역이라는 이유만으로 직접 경쟁으로 정하지 않는다. 비교 목적 미지정은 참고로 유지한다.
- 예약률은 공통 유효 숙박일의 예약 객실 수 합계 / 같은 날짜의 공급 객실 수 합계다. 공통 7일은 최소 표본 조건이며 통계적 신뢰를 보증하지 않는다.
- 정상 수량, 가격 미확인, 객실 기준 충돌, 관측 날짜·시각 차이와 공백의 사유를 따로 제공한다. 확인된 금액 소계는 유지하고 미확인 날짜·금액을 0으로 만들지 않는다.
- 현재 자료는 최근 7일의 관측을 사용한다. 과거 자료는 명시한 숙박기간과 관측 마감일을 사용하며 현재 신선도 기준으로 제거하지 않는다. 과거 기간 HTTP 조회는 4단계에 연결한다.
- 같은 업체·같은 숙박일을 중복 가산하지 않는다. 서로 충돌하는 중복 투영은 중앙 자료 확인 대상으로 남긴다. 원본의 관측 선택·객실·데이유즈·매출 산식을 새로 만들지 않는다.
- 공식 지역 키와 명시적 지역 계층 매핑만 사용한다. 이름·주소 일부로 지역이나 업종을 추측하지 않는다.

## 공통 선택 상태

`customer-portal/web/comparison-selection.js`의 독립 모듈을 구현했다. 기준 내 매장, 비교업체 집합, 향후 30일/숙박월/사용자 기간, 관측 기준일, 예약 흐름/가격·상품/지역 배경 보기를 관리한다.

- URL과 같은 계정·권한 범위의 세션 저장에서 선택을 복원한다. 인증키, 비밀번호, 고객 메모, 전체 주소는 저장하지 않는다.
- 내 매장 변경 시 종속 업체 선택을 초기화한다. 권한 축소·등록 해제·계정 변경 시 늦게 온 응답을 제외한다.
- 한국시간 자정에는 향후 30일을 새 날짜로 이동한다. 과거월 마감일은 유지한다.
- 비정상 날짜·과도한 기간·권한 없는 업체를 거부하고 직전 정상 선택을 유지한다.
- URL은 완전한 선택 스냅샷이다. 비교업체가 비어 있으면 이전 업체 선택을 되살리지 않는다.

## 저장 자료 호환

인사이트 `comparison-projection.cjs`와 기존 `report-read-cache.cjs`를 연결했다. 새 비교 계약이 있으면 필드 전체, 업체·기간·지역·관측 시각·품질·행동 조건을 검사한다. 불완전한 새 계약을 구형 응답으로 바꾸지 않는다.

기존 영속 캐시 이름공간과 정상 숫자·확인 시각을 유지한다. 구형 저장 자료는 참고로 읽되 새 비교 근거가 없는 `compare`/`track` 행동 안내는 검토 안내로 바꾼다. 기존 발행본 파일은 수정하지 않는다. 미래 비호환 계약은 저장 버전 변경 또는 이전 자료 읽기 전환이 별도로 필요하다.

현재 행동 자료에 대상 업체 번호가 없어 문구 속 업체까지 엄격하게 결합할 수 없다. 이후 행동 계약에 `targetCompanyId`를 추가해야 한다.

## PC·모바일 시안

로컬 주소: `http://127.0.0.1:57995/`

실행:

```powershell
$env:INSIGHT_STAGE1_REVIEW_PORT='57995'
node customer-portal/review/comparison/server.cjs
```

시안은 **명시적으로 표시한 가상 검수 자료**다. 실제 월명글램핑·고객·판매 관측값이 아니다. 동일지역·타지역·혼합, 산청/가평 기준 매장, 0/미확인, 가격 일부 미확인 사례를 같은 중앙 비교 모듈로 처리한다. 현재 여섯 메뉴 중 경쟁분석을 상세 구현했고 나머지는 공통 선택 유지와 후속 화면 구성을 확인하는 시안이다. 실제 업체자료·지역지표 조회 연결은 다음 단계다.

서버는 localhost에만 바인딩하며 GET/HEAD와 지정한 파일만 제공한다. 수집·명령·서버 파일 경로를 제공하지 않는다. 시안의 허용 관측 시차 2시간은 QA 전용 예시다. **운영 정책값은 확정하지 않았고, 운영 자동 행동 판단은 보류한다.**

## 배포 전 경계

중앙과 인사이트의 기준 커밋이 다르므로 전체 브랜치를 서로 덮어쓰지 않는다. 중앙 비교 연결부와 인사이트 표시 연결부만 각각 검수한다. 수집 실행·예약·보호 설정·운영 DB·원본·발행본·서버 배포는 이번 1단계 작업에서 변경하지 않았다. 2단계는 실제 저장 자료 연결을 진행하며 과거월 HTTP 조회·경쟁지역 파생 권한·발행 구조는 후속 범위다.
