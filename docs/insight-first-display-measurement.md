# Insight 첫 업체자료 표시 계측

브라우저의 `performance` 표시는 실제 화면 준비 시점과 외부 검수 도구의 선택자 대기를 구분하기 위한 관측 정보다. 이 계측 자체가 조회 속도를 개선했다는 뜻은 아니다.

한 문서에서 다음 이름을 각각 한 번만 기록한다. 새로고침이나 새 탭은 새 문서이므로 다시 시작하고, 같은 문서의 메뉴 전환·반복 표시에서는 추가하지 않는다. 따라서 문서당 최대 3개다.

| 표시 이름 | HTML 루트의 읽기 전용 계측 속성 | 기록 조건 |
| --- | --- | --- |
| `insight-bootstrap-start` | `data-insight-bootstrap-start-ms` | HEAD의 선행 조회 코드가 시작됨 |
| `insight-identity-ready` | `data-insight-identity-ready-ms` | 현재 페이지의 중앙 인증 GET이 성공함. 고객은 현재 `/me`에서 계정이 확인된 뒤, 관리자 고객 화면은 관리자 `/me`에서 인증이 확인된 뒤 기록 |
| `insight-company-data-ready` | `data-insight-company-ready-ms` | 인증 후 허용된 업체의 실제 저장 자료 또는 정상 GET 자료가 현재 업체 경로의 DOM에 반영됨 |

계측 속성은 `document.documentElement`에 최대 3개만 추가하며 값은 해당 문서의 시간 원점에서 경과한 밀리초 숫자다. `PerformanceMark.startTime`을 사용하고 반환값이 없는 지원 환경에서는 `performance.now()`를 사용한다. 소수점 3자리 숫자 문자열만 저장하며, DOM의 `getAttribute`로 읽기 전용 검수가 가능하다. 계정·업체 식별자나 실제 자료를 속성에 넣지 않는다. 계측 API나 DOM 속성 쓰기가 지원되지 않아도 기존 조회 흐름을 유지한다.

업체 기본목록에서 만든 임시 안내 화면, 요청 시작, 백그라운드 예열만 끝난 상태에는 업체자료 표시를 기록하지 않는다. 이미 떠난 경로나 다른 업체의 늦은 응답도 기록하지 않는다. 오류·권한 거부를 성공이나 0으로 간주하지 않는다.

이름과 브라우저 상대시각만 기록한다. 업체·계정 식별자, 객실·매출 수치, 응답 본문, 쿠키·토큰은 포함하지 않으며 저장소나 서버로 전송하지 않는다. `performance` 미지원이나 계측 실패는 화면 기능을 막지 않는다.

측정 시 새로고침 시작 시각, 선행 조회 시작, 인증 완료, 실제 업체자료 DOM 반영, 외부 검수 도구 완료를 분리해 확인한다. `insight-company-data-ready`는 DOM 반영 시점이며 화면의 다음 페인트 완료나 백그라운드 최신 확인 완료를 뜻하지 않는다. 인증 전 캐시 표시를 허용하지 않으며 기존 최신 확인·실패 처리·폴링 제한을 바꾸지 않는다.
