5. 세 판단 카드에서 예약 수준·상품 가격 조건·예약 증가 관측구간의 수치와 검토 행동을 보여준다. 상태는 `reference_only` 또는 `hold`이며 전문가 승인·할인율·자동 실행 권한을 부여하지 않는다.
