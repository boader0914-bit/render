# 월간 리포트의 저장 배후시장 연결

`createMonthlyReportCatchmentContext({catchmentService, now})`는 기존 `regionalCatchmentService.get({regionKey})`만 호출한다. 원본 CSV·격자, 공급자, 계산·갱신·작업 등록 API는 사용하지 않는다. 월간 서비스·화면·PDF 연결은 별도 통합 범위다.

반환 함수는 `(request, roster, {asOfAt})`를 받는다. 업체는 해당 업체의 확인된 실제 지역, 키워드는 그 보고월 대상 업체의 실제 지역, 지역 보고서는 명시한 지역을 사용한다. 키워드 지명 추론·임의 지역 대체·지역 간 합산은 하지 않는다. 광역·비활성·지원하지 않는 지역은 미확인 사유를 남긴다.

결과의 `entries[].snapshot`은 기존 검증을 통과한 저장 결과의 분리 복사다. 결과 ID, 계산 버전·시각, 입력 지문, 확인한 중심점, 자료 ID, 통계연도·경계연도, 원본·변환 해시, 3개 반경 구간과 3개 지표의 공개합·보호·누락·전체값 상태를 보존한다. 기관의 출처 URL과 관리자 반입 선언을 독립 인증으로 승격하지 않는다. 개별 반입자·검수자·내부 작업 원문은 복사하지 않는다.

연간 기초자료는 보고월의 월간 값이나 고유 고객 수·예약 수요가 아니다. `cutoffDate`는 숙박 관측 마감, `asOfAt`은 보고서 작성 당시 저장 자료를 확인한 시점이다. 원래 저장 산출시각이 관측 마감 이후여도 작성시점 이전이면 연간 참고 자료로 연결할 수 있으며, 작성시점 이후 산출물은 제외한다. 발행 후 새 자료 반영은 기존 수정본 절차의 책임이다.

지역은 최대 24개, 저장 결과당 JSON은 최대 32KiB, 3구간×3지표, 주석은 최대 12개로 제한한다. 전체/포함/생략 지역 수와 소재지 미확인 업체 수를 별도로 남긴다. `snapshot:null`은 0이 아니다. 정상 공개 0은 유지하고 보호 0은 실제 0으로 바꾸지 않는다. 갱신 실패 시 유효한 이전 저장본은 `stale`와 그 사유를 함께 보존한다. 서비스 미연결·오류·조건 불일치는 `unavailable`로 표시한다. 외부 작업을 시도한 응답은 정상 배경 자료로 흡수하지 않고 cache-only 계약 오류로 거부한다.

검증: `node --test scripts/test_monthly_report_catchment_context.cjs`. 합성 격자와 임시 폴더만 사용하며 실제 서비스의 저장 결과는 격자 원본을 다른 경로로 옮긴 뒤 재시작하여 읽는다. 저장 상태 파일 불변·계산 0·결과 ID 재사용·0과 미확정 구분·선택 범위·무결성·시간·출력 경계를 확인한다. 운영 배포·실제 통계 반입·운영 성능은 이 검증으로 주장하지 않는다.
