# 월간 리포트의 저장 배후시장 연결

`createMonthlyReportCatchmentContext({catchmentService, now})`는 저장 결과의 `get`만 호출한다. 원본 CSV·격자, 공급자, 계산·갱신·작업 등록 API는 사용하지 않는다.

반환 함수는 `(request, roster, {asOfAt})`를 받는다. 업체는 **업체 ID와 원장에 저장된 고유 상세 주소**를 사용하고, 키워드는 보고월 대상 업체마다 개별 주소의 배후시장을 연결한다. 같은 시군구라는 이유로 서로 다른 업체를 한 기준점으로 합치지 않는다. 지역 보고서는 명시적으로 확인한 지역 분석 기준 주소를 사용하며 숙소 주소로 표시하지 않는다. 키워드 지명 추론·지역 중심점·지도 표시용 추정 좌표·임의 지역 대체·반경 간 인구 합산은 하지 않는다.

## 주소지 기준점

- 현재 업체 원장의 상세 주소가 하나로 확정돼야 한다. 같은 문자열의 공백·NFKC 정규화만 허용한다. 서로 다른 도로명/지번 주소를 근거 없이 같은 주소라고 추측하지 않는다. 주소 없음은 `missing`, 서로 다른 주소가 여럿이면 `ambiguous`로 남긴다.
- 신규 기준점은 `address`, 주소 SHA, 위도·경도, 명칭, 대조한 출처 URL, 관리자 확인을 함께 저장한다. 업체 기준점은 `companyId`까지 묶는다. 좌표는 그 주소와 같은 위치임을 대조해야 하며, 관리자 대조 기록을 독립 지오코딩 검증으로 표현하지 않는다.
- 설정/계산은 현재 업체 원장의 주소·소재지와 대조한다. 주소 변경 또는 미확정 전환 시 이전 결과를 새 주소 결과로 노출하거나 재사용하지 않는다. 진행 중 계산도 게시 직전 재확인한다.
- 새 월간 미리보기는 원자료 버전 검사를 거친 업체 주소를 읽고 `{regionKey,companyId,address}`로 저장 결과를 정확히 조회한다. 별도의 원장 전체 읽기나 외부 좌표 변환을 매 업체 조회마다 수행하지 않는다. 주소 근거는 월간 재사용 캐시에도 보존한다.
- 주소 없는 기존 설정/결과와 과거 발행본은 덮어쓰거나 소급 수정하지 않는다. 기존 결과는 이전 기준의 근거로 읽을 수 있지만, 새 주소 기준 월간 보고서에 연결하거나 주소 없는 새 계산에 쓰지 않는다.

이번 변경은 주소→좌표 외부 변환 API를 추가하거나 운영 좌표를 일괄 갱신하지 않는다. 현재 원장 주소 선택과 좌표·출처 대조 계약을 구현한 것이며, 저장 좌표 또는 격자 통계가 없으면 배후시장 숫자는 계속 미확인이다.

결과의 `entries[].snapshot`은 기존 검증을 통과한 저장 결과의 분리 복사다. 결과 ID, 계산 버전·시각, 입력 지문, 확인한 중심점, 자료 ID, 통계연도·경계연도, 원본·변환 해시, 3개 반경 구간과 3개 지표의 공개합·보호·누락·전체값 상태를 보존한다. 기관의 출처 URL과 관리자 반입 선언을 독립 인증으로 승격하지 않는다. 개별 반입자·검수자·내부 작업 원문은 복사하지 않는다.

연간 기초자료는 보고월의 월간 값이나 고유 고객 수·예약 수요가 아니다. `cutoffDate`는 숙박 관측 마감, `asOfAt`은 보고서 작성 당시 저장 자료를 확인한 시점이다. 원래 저장 산출시각이 관측 마감 이후여도 작성시점 이전이면 연간 참고 자료로 연결할 수 있으며, 작성시점 이후 산출물은 제외한다. 발행 후 새 자료 반영은 기존 수정본 절차의 책임이다.

주소 기준 대상은 최대 24개, 저장 결과당 JSON은 최대 32KiB, 3구간×3지표, 주석은 최대 12개로 제한한다. 전체/포함/생략 지역 수와 주소 기준 대상 수, 소재지 미확인 업체 수를 별도로 남긴다. `snapshot:null`은 0이 아니다. 정상 공개 0은 유지하고 보호 0은 실제 0으로 바꾸지 않는다. 갱신 실패 시 유효한 이전 저장본은 `stale`와 그 사유를 함께 보존한다. 서비스 미연결·오류·조건 불일치는 `unavailable`로 표시한다. 외부 작업을 시도한 응답은 정상 배경 자료로 흡수하지 않고 cache-only 계약 오류로 거부한다.

검증: `node --test scripts/test_monthly_report_catchment_context.cjs`. 합성 격자와 임시 폴더만 사용하며 실제 서비스의 저장 결과는 격자 원본을 다른 경로로 옮긴 뒤 재시작하여 읽는다. 저장 상태 파일 불변·계산 0·결과 ID 재사용·0과 미확정 구분·선택 범위·무결성·시간·출력 경계를 확인한다. 운영 배포·실제 통계 반입·운영 성능은 이 검증으로 주장하지 않는다.
