# 인사이트 지역분석 재조회

지역분석의 계정·지역·기준월별 이전 결과를 먼저 보여 주고, 저장자료 GET으로 변경 여부를 확인한다. 데이터랩과 수집기는 변경하지 않는다.

- 로그인된 페이지의 메모리에 최대 24개 결과를 30분간 보관한다. 브라우저 저장소에는 개인별 결과나 인증 자료를 저장하지 않는다.
- 인사이트 서버도 세션별로 지역 결과를 보관한다. 새로고침의 `/me` 응답은 중앙 로그인·이용 상태·현재 허용 지역을 확인한 뒤에만 `regionViews`를 포함한다.
- 각 지역 GET은 중앙 권한을 다시 확인한다. 같은 요청의 진행 중 확인만 공유하며, 완료된 인증 성공을 일정 시간 재사용하지 않는다.
- 같은 지역·기준월의 서버 결과는 30초 동안 재사용하고 이후에는 이전 결과를 반환하면서 자료 GET 한 건으로 갱신한다. 화면은 제한된 횟수의 후속 GET으로 갱신 완료를 확인한다.
- 지역이나 기준월이 바뀐 응답이 현재 화면을 덮지 않도록 요청 순서와 허용 지역을 검사한다. 값이 같으면 차트 선택과 펼침 상태를 유지한다.
- 최신 자료 조회 실패 시 마지막 정상 결과와 실패 안내를 함께 표시한다. 인증 만료나 조회 권한 해제 시에는 해당 자료를 제거한다. 정상 0과 미확인 수치는 그대로 구분한다.
- 지역 자료의 직접 갱신은 기존 명시적 버튼으로만 요청한다. 캐시 복원·화면 진입·새로고침으로 자료 수집 POST를 실행하지 않는다.

공개 지역 결과는 기존 인사이트 영속 디스크의 `/var/data/insight-region-cache`에도 저장한다. `INSIGHT_REGION_CACHE_DIR`로 전용 절대 경로를 지정하거나 `DATA_DIR` 아래에 만들 수 있다. Render는 기존 `/var/data`를 기본 사용하며, 로컬 실행은 경로를 명시하지 않으면 파일을 만들지 않는다.

- 공개 필드만 다시 추려 저장하며, 계정·세션·토큰·권한 판단은 저장하지 않는다. 중앙 서버 주소·표시 규칙·지역·기준월이 정확히 같은 결과만 재사용한다.
- 시작 시 파일 크기·체크섬·자료 형태·확인 시각을 검증하여 준비한다. 재시작 뒤 `/me`와 지역 GET은 현재 로그인·허용 지역을 확인한 다음에만 저장 결과를 새 세션에 연결한다.
- 파일은 원래 확인 시각부터 최대 7일 유지한다. 복원할 때 확인 시각을 현재로 바꾸지 않으며, 오래된 자료에는 마지막 확인 시각과 최신 확인 안내를 표시한다. 실제 새 자료를 확인하면 일반 30분 메모리 캐시로 돌아간다.
- 재시작 뒤 첫 지역 GET은 복원 결과를 바로 반환하면서 중앙 저장자료를 뒤에서 확인한다. 로그인 복원 자체는 지역 자료를 재계산하거나 외부 API를 수집하지 않는다.
- 서버 주소·표시 규칙별 저장은 최대 128건·16MiB이며, 파일 한 건은 최대 512KiB다. 임시 파일을 동기화한 뒤 원자적으로 교체하고 늦은 이전 쓰기를 차단한다. 32MiB 여유 공간을 보호하며 저장에 실패하면 마지막 정상 파일을 보존한다.

저장본이 없거나 7일을 넘었거나 손상된 조건은 기존 중앙 저장자료 조회로 돌아간다. 원본 자료와 월간 분석 결과를 변경하거나 재계산하는 기능이 아니다.

검수는 지역·월 전환, 같은 요청의 중복 공유, 원본 수치 변경, 일시 실패, 인증 만료, 등록 해제, 계정·관리자 구분, 새로고침 복원과 늦은 응답을 포함한다. 저장소와 인사이트 서버를 새 인스턴스로 다시 만들어 원래 확인 시각이 유지되는지도 확인한다. 배포 후 실제 운영 계정에서 저장 결과를 만든 뒤 인사이트만 재시작하고 첫 로그인 확인·자료 표시 시간을 기록한다.
