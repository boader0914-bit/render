# 인사이트 지역분석 재조회

지역분석의 계정·지역·기준월별 이전 결과를 먼저 보여 주고, 저장자료 GET으로 변경 여부를 확인한다. 데이터랩과 수집기는 변경하지 않는다.

- 로그인된 페이지의 메모리에 최대 24개 결과를 30분간 보관한다. 브라우저 저장소에는 개인별 결과나 인증 자료를 저장하지 않는다.
- 인사이트 서버도 세션별로 지역 결과를 보관한다. 새로고침의 `/me` 응답은 중앙 로그인·이용 상태·현재 허용 지역을 확인한 뒤에만 `regionViews`를 포함한다.
- 각 지역 GET은 중앙 권한을 다시 확인한다. 같은 요청의 진행 중 확인만 공유하며, 완료된 인증 성공을 일정 시간 재사용하지 않는다.
- 같은 지역·기준월의 서버 결과는 30초 동안 재사용하고 이후에는 이전 결과를 반환하면서 자료 GET 한 건으로 갱신한다. 화면은 제한된 횟수의 후속 GET으로 갱신 완료를 확인한다.
- 지역이나 기준월이 바뀐 응답이 현재 화면을 덮지 않도록 요청 순서와 허용 지역을 검사한다. 값이 같으면 차트 선택과 펼침 상태를 유지한다.
- 최신 자료 조회 실패 시 마지막 정상 결과와 실패 안내를 함께 표시한다. 인증 만료나 조회 권한 해제 시에는 해당 자료를 제거한다. 정상 0과 미확인 수치는 그대로 구분한다.
- 지역 자료의 직접 갱신은 기존 명시적 버튼으로만 요청한다. 캐시 복원·화면 진입·새로고침으로 자료 수집 POST를 실행하지 않는다.

서버 캐시는 인사이트 프로세스의 제한된 메모리이며, 재배포·재시작 후 최초 조회는 중앙 저장자료를 다시 읽는다. 최초 조회와 이미 조회한 조건의 재방문 속도는 구분해서 검수한다. 원본 자료와 월간 분석 결과를 변경하거나 재계산하는 기능이 아니다.

검수는 지역·월 전환, 같은 요청의 중복 공유, 원본 수치 변경, 일시 실패, 인증 만료, 등록 해제, 계정·관리자 구분, 새로고침 복원과 늦은 응답을 포함한다. 배포 후 실제 운영 계정에서 내 매장과 지역분석을 왕복하고 새로고침하여 DOM의 실제 자료 표시 완료 시간과 HTTP 응답을 별도로 기록한다.
