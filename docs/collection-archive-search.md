# 결과 보관함 검색

2026-09-26 개발. 운영 배포 및 실제 네이버 수집은 별도다.

- 수집일 시작·종료(한국시간, 양 끝 날짜 포함), 키워드 일부 일치, 수집기, 저장 결과의 품질 상태를 함께 검색한다. 키워드는 공백·대소문자·전각 차이를 정규화한다.
- 오늘, 최근 7일(오늘 포함), 이번 달(오늘까지), 전체 기간을 빠르게 선택한다. 날짜를 직접 입력하면 검색 버튼 또는 Enter로 적용한다. 잘못된 날짜 범위는 이전 검색 결과를 유지하며 오류를 표시한다.
- `/api/runs` 전체 목록을 먼저 필터링한 뒤 20건씩 페이지를 나눈다. 40건 제한을 없애고 처음·이전·다음·마지막 페이지를 제공한다. 기본 정렬은 실제 수집일 최신순이며 수집일 미확인 자료는 뒤에 표시한다.
- 실제 수집일은 `collectedAt`이다. `updatedAt`(폴더 수정시각)을 수집일 검색에 사용하지 않는다. `collectedAtSource=filesystem` 또는 유효한 수집시각이 없는 기록은 날짜 범위 검색에서 제외하고, 제외 건수와 미확인 자료 보기 기능을 제공한다.
- 조회한 숙박기간은 `analysisRunPeriodLabel`을 사용해 수집일시와 다른 열에 표시한다. 당일은 1일, 31일 수집은 체크인부터 30일 후까지의 숙박일을 표시한다.
- 워커와 품질이 기록되지 않은 과거 자료는 각각 수집기 미확인·상태 미확인으로 표시한다. 완료라고 추정하지 않는다. 파일 없이 끝난 실패·대기 요청은 기존 수집 기록에서 조회하며, 보관함은 저장된 결과만 다룬다.
- 목록 새로고침은 `GET /api/runs`만 호출하며 현재 분석 결과를 자동으로 바꾸거나 수집을 실행하지 않는다. 검색조건·입력 중 초안·페이지는 가능한 범위에서 유지한다.
- 데스크톱은 비교하기 쉬운 6열 목록, 좁은 화면은 항목명이 붙은 카드로 표시한다. 기존 라이트·다크 테마 토큰을 사용한다. 플레이스 순위 비교는 목록 아래 접힌 영역에 둔다.
- 수집 화면의 2G 서버 중앙 보관 안내 배너는 제거했다. 결과 저장·전송 동작은 변경하지 않았다.
