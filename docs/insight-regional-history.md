# 인사이트 지역 분석: 최근 12개월 흐름

2026-10-03 개발 및 두 웹 서비스 운영 배포. 실제 고객 화면 검수 범위는 [운영 배포 기록](insight-company-views-release-20261003.md)을 따른다.

## 기간과 지표

- 마지막 기준월은 한국시간 기준 직전 마감월을 기본으로 한다. 2026년 10월 조회 시 표시 구간은 2025-10~2026-09, 전년 비교용 확보 구간은 2024-10~2026-09다.
- 지역 방문자, 체류·소비 지수, 관광자원 수요 지수, 관광 다양성 지수, 검색 관심도를 월별 그래프와 표로 표시한다. 카드별 최신 확보월과 12개월 중 확보한 월 수를 명시한다.
- 최신 확보월과 정확히 한 달 전, 정확히 12개월 전을 비교한다. 중간 월이 없으면 앞선 유효 월로 대체하지 않는다. 방문 인원은 증감률, 지수는 지수 차이로 표시한다. 기준값이 0인 증감률은 계산하지 않는다.
- 누락·실패·부분 응답은 정상 0과 구분하고 그래프 선을 끊는다. 최고·최저는 확보 자료 안의 값이다. 방문자 누계의 단위는 인일이며 순방문자 수가 아니다.
- KOSIS 인구·산업은 실제 공표기간을 표시하는 배경 통계로 유지한다. 연간 통계를 월별로 복제하거나 과거 월 당시의 확정값이라고 표시하지 않는다.
- 진행 중인 이번 달의 저장 자료는 별도 접기 영역으로 표시하며 마감월 비교에 포함하지 않는다. 이번 달 검색자료가 아직 없으면 없는 상태로 표시한다. 이 버튼은 마감월까지의 이력만 준비한다.

## 검색 관심도

24개월 전체를 네이버 데이터랩의 단일 요청으로 조회한다. 기존 12개월 요청의 저장 자료는 별도로 유지하며 독립된 조회기간의 지수를 이어 붙이지 않는다. 24개월 저장 자료가 전혀 없으면 기존 12개월 자료를 통째로 표시할 수 있지만 전년 비교는 미확인이다.

검색어는 기존 데이터랩의 시군구별 기준 검색어(지역명+글램핑)를 사용한다. 지역 전체의 모든 숙박업종 검색량을 뜻하지 않는다. 같은 요청의 최고값 100인 상대지수이므로 다른 지역·검색어·조회기간과 직접 합산하지 않는다. [네이버 검색어 트렌드 공식 안내](https://developers.naver.com/docs/serviceapi/datalab/search/search.md).

## 조회와 갱신

- 지역 분석 및 현재 상황 브리핑 조회는 저장 자료만 읽는다. 관광 API, 네이버 API나 숙박 크롤러를 자동 실행하지 않는다.
- 고객은 등록 관심지역과 연결이 완료된 내 매장 소재지에만 `지역 자료 갱신`을 요청할 수 있다. 관리자 고객 화면도 같은 경로를 사용한다.
- 인사이트 BFF가 인증된 요청을 데이터랩으로 전달한다. 제공기관 인증키는 브라우저로 보내지 않는다. POST는 로그인, CSRF, 동일 출처 및 등록 지역 검사를 거친다.
- `GET/POST /api/customer/v1/regions/{regionKey}/preparation`과 관리자 고객 화면의 대응 경로를 제공한다. 요청 조건은 마지막 기준월 하나다. 임의 지역, 임의 키워드, 강제 갱신 옵션을 허용하지 않는다.
- 6단계는 방문자 → 체류·소비 → 관광자원 → 다양성 → KOSIS → 검색 트렌드다. 관광 이력은 24개월을 검사해 누락 자료를 순차 준비하고 KOSIS는 기존 저장 자료의 유효기간을 따른다.
- 같은 지역·기준월은 고객 간 작업을 공유한다. 실행 중 중복 등록을 막고, 종료된 결과는 1시간 재사용한다. 이 정책은 실패·부분 종료에도 적용되므로 즉시 반복 요청으로 제공기관을 재호출하지 않는다.
- 기존 관광 API 동시 실행 보호, 체류·소비 일일 요청 예산, 검색 트렌드 24시간 캐시와 오류 처리를 유지한다. 재시작 시 미완료 작업을 자동 재실행하지 않는다.
- 진행 상태는 `DATA_DIR/insight_region_preparation`에 별도 저장한다. 실제 통계는 기존 관광/KOSIS/검색 저장소를 공유한다. 데이터랩 월간 리포트의 기존 1개월 자료 준비 정책은 유지한다.

## 배포 및 확인 범위

데이터랩 웹 서버와 인사이트 웹 서버에 같은 변경을 배포해야 한다. 숙박 수집 워커 변경은 필요하지 않다. 배포 후 지역 분석의 기간, 등록 지역 권한, 갱신 상태, 실제 API 응답과 확보 월 수를 따로 검수한다. 개발 테스트와 가상 UI 예시는 실제 API 24개월 수집 완료의 근거가 아니다.

관련 검증: `test_insight_region_history.cjs`, `test_insight_analysis.cjs`, `test_insight_app_integration.cjs`, `test_regional_report_preparation.cjs`, `test_regional_search_trends.cjs`, `test_tourism_collector.cjs`, 고객 포털 테스트. 개발 중 실제 외부 API 갱신, 숙박 수집, 운영 설정 변경은 실행하지 않았다.
