# 입지사전 방문자 표시와 수요 전망 연결 수정

기준: UI 전수 점검 커밋 `3480952` 이후 추가 수정. 운영 배포는 수행하지 않았습니다.

## 변경

- 지역 방문자 누적 숫자를 PC 최대 32px에서 22px, 모바일 24px에서 20px로 축소했습니다. 다른 지표 카드의 크기와 행 정렬은 유지합니다.
- 관광 지표 선 그래프의 최신값 상자를 SVG 내부에서 제거하고, 그래프 아래의 일반 문서 흐름에 날짜·값·단위를 표시합니다. 관측점, 결측 구간, 접근성 설명과 원본 값은 유지합니다.
- 방문자 카드의 `최신 완전월` / `최근 완전월`을 `최근 수집 완료 월`로 바꾸고 날짜 옆에 `모든 날짜 자료 확보`를 표시합니다. 이는 해당 달의 모든 날짜와 방문자 구분 자료가 확보되고 지역코드·중복 검증을 통과했다는 기존 수집 기준입니다. 달력상 직전 달과 다를 수 있습니다.
- 수요 화면의 최상위 이름을 `수요 전망`으로 통일했습니다. 기존 검색 추세와 시즌 수요구조를 분석하는 기능이며, 새로운 미래 방문자 수 예측 모델을 추가하지 않았습니다.
- 입지사전의 상단·카드 수요전망 버튼에서 선택지역 문맥을 전달합니다. 선택지역에 연결된 정확한 수집 키워드가 아니면 다른 지역의 수치를 표시하지 않습니다. 동명지역은 지역코드 근거까지 확인하고 혼합 지역도 차단합니다. 해당 화면에 선택지역, 현재 키워드, 필요한 키워드를 안내합니다.
- 직접 수요 메뉴는 기존 수집결과 기준 동작을 유지하며, 브라우저 뒤로가기는 선택지역 문맥을 복원합니다.

## 확인

운영 API에 쓰기 요청을 하지 않는 로컬 화면에서 기존 저장 응답을 사용했습니다. 신규 수집, 데이터 변경, 공급기관 API 호출은 하지 않았습니다.

| 항목 | 결과 |
| --- | --- |
| PC 1440px 라이트·다크 | 방문자 숫자 22px, 그래프와 최신값 표기 영역 분리 |
| 모바일 390px 라이트·다크 | 방문자 숫자 20px, 가로 넘침 없음, 최신값이 선을 가리지 않음 |
| 입지사전 산청 → 상단 수요전망 | 마지막 포천 수집 수치를 숨기고 산청 자료 대기 안내 |
| 입지사전 산청 → 카드 지역 수요전망 | 동일한 지역 불일치 차단 확인 |
| 자료 대기 안내 | PC 라이트·모바일 다크에서 글자 대비와 카드 줄바꿈 확인 |
| 기본 검사 | `pnpm run check` 통과 |
| 관광 그래프 회귀검사 | `test_location_profile_tourism_ui.cjs` 통과 |
| 지역 연결 회귀검사 | `test_dictionary_demand_context.cjs` 통과 |
| 기존 검색·내비게이션·오버레이 | 각각 12 / 116 / 16개 통과 |

지역 연결 검사는 정확 일치, 다른 지역, 광역 자료, 동명·혼합 지역, 미선택, 미연결, 자료 없음, 직접 메뉴, 뒤로가기 복원을 확인합니다. 그래프 검사는 최신값이 SVG 밖에 있는지와 관측점·결측 표현 보존을 확인합니다.

누적 방문자는 주민등록 인구가 아니라 기간 내 방문자료의 합계입니다. 반복 방문을 제거한 고유 인원으로 해석하지 않습니다. 실제 단말과 운영 배포 이후 화면 확인은 별도입니다.
