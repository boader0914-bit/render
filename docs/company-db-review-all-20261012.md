# 업체 DB 전체 검토 카드 공통화

우이동가족캠핑장의 검수 도구에 한정됐던 테마 적용을 모든 업체의 상세 검토 화면으로 확대한다. 공통 `.admin-db-review-surface`에 적용하므로 업체별 별도 수정 없이 같은 UI를 사용한다.

## 적용 범위

- A 기본정보·상품별 가격, B 예약 채널, C 최근 운영 관측, D 누적 이력·관리.
- 월별 통합 분석의 지표·탭·그래프·캘린더·자료 검토 카드.
- 기본정보·기준값·채널 보정·수집·검수 도구 및 검수 보조자료.
- 카드 표면·테두리·간격·제목·설명·입력·버튼을 공통 라이트/다크 토큰으로 맞춘다.
- 메뉴·검수 상태·수집 범위·보정 후 처리의 선택 표시를 hover 중에도 보존한다. 저장 버튼은 공통 강조색과 대비 글자를 사용한다.
- 상품 가격표는 PC에서 표 안에서만 좌우 이동하며 모바일에서는 기존 상품별 항목 형식을 유지한다. 상품 더보기와 객실 종류는 유지한다.
- 모바일 컨트롤은 최소 44px이며 텍스트 입력은 16px이다. 공개예약 녹색·타채널 추정 보라색·객실 신뢰도 경고와 미확인 표시는 유지한다.

범위는 운영 관리자 업체 검토 UI다. 원본·업체 검수값·집계 계산·수집/예약/보호 설정을 변경하지 않으며 인사이트·BG·AWS 워커는 배포 대상이 아니다.

## 검증

- 실제 렌더 함수로 A/B/C/D·통합 카드 mount·검토 도구·형제 보조자료의 공통 영역 연결을 검사한다. 실제 상품 6개 더보기와 객실 경고도 검사한다.
- CSS의 선택자 우선순위와 선언 순서로 저장 버튼 및 선택 상태의 일반/hover 스타일을 검사한다. 모바일 버튼의 기존 42px 규칙과의 충돌도 확인한다.
- 테마 대비 검사 통과: 라이트 71개·다크 25개 선택자, 예약 색상 16개 검사, 최저 대비 4.73:1.
- 검토 메뉴·업체 수정 바로가기·통합 UI 회귀 10개, 운영 관측 및 이력의 예약 색상 회귀 3개 통과.
- 외부 통신·수집·스케줄을 차단한 실제 로컬 서버와 모의 업체를 사용했다. 상품 6개·객실 종류 2개·공개/타채널 자료·객실 경고를 표시한 업체에서 PC 1280px 및 모바일 390px, 양 테마의 메뉴 5개 전환 총 20회를 확인했다. 선택/접근성 상태와 펼쳐진 도구가 일치한다.
- 좁은 화면의 문서 폭은 390px으로 가로 넘침이 없다. 상품 가격표는 PC 카드 폭 463px 안에서 내용 폭 650px을 좌우로 이동한다. 상세 상품 없는 업체는 PC 양 테마, 완전 미관측 업체는 PC/모바일 양 테마에서 확인했다. 미관측 예약·매출은 모두 미확인으로 유지한다.
