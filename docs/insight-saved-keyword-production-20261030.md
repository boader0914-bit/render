# 인사이트 저장 키워드 비교 운영 연결 · 2026-10-30

## 제공 범위

관리자 고객 화면의 **경쟁 분석 → 저장 키워드 비교 → 비교 화면 열기**에서 같은 인사이트 도메인의 전체 비교 화면을 새 창으로 연다. 기존 `#saved-keyword-comparison` 주소는 과거 자료의 범위와 열기 버튼을 보여주는 진입 화면으로 유지한다.

첫 운영 검수에서 본문 iframe이 준비 중 상태에 머무르는 반면, 인사이트 화면의 링크를 통해 연 전체 화면에서는 동일한 보호 자료와 모든 기능이 정상 표시됐다. 최종 진입은 이 확인된 전체 보기 경로를 사용하며 iframe·HEAD 사전 조회·무한 로딩을 제거한다.

이번 표본은 **경남글램핑 2026-09-20·21·22 관측**을 사용한 월명 글램핑과 상위 20개 업체의 검토 자료다. 실제 선택한 고객의 현재 내 매장·경쟁업체 자료와 바꾸어 표시하지 않는다. 일반 고객 메뉴에 노출하거나 모든 고객에게 과거 20개 업체의 자료를 제공하지 않는다.

## 인증과 자료 경계

- HTML과 해시 JSON 모두 매 요청 활성 인사이트 관리자 세션을 검증한다. 비로그인 401, 일반 고객 403, POST 405다.
- 중앙 데이터랩 호출은 기존 `/admin/me`의 관리자 **인증 확인**만 사용한다. 이 기능이 업체 자료·키워드 자료·수집·예약 API를 호출하지 않는다.
- 별도 고객 선택 상태와 기존 실제 업체 화면을 유지한다. 저장 비교 진입에서는 실시간 비교·분석·정기수집 상태 조회를 시작하지 않는다.
- 구형 해시 진입의 로그인 준비 단계는 기존 settings의 identity-only 범위를 재사용해 회사·지역·리포트 자료를 미리 계산하지 않는다. 설정 화면 자체를 열거나 바꾸는 동작은 아니다.
- 공개 프런트 코드에는 수집 원본을 넣지 않는다. 자료 번들은 관리자 보호 경로 `/saved-keyword-comparison/`에서만 제공한다.
- 배포 번들의 HTML·JSON은 SHA-256과 크기를 확인한 뒤 스트리밍한다. 변조 시 503으로 보류하며 서버에서 전체 JSON을 반복 파싱하지 않는다.

- 자료: `ce38eac81ff9f47974ccbb96190e247accf3d0c1b549e952203845adeb254586`.

비교 계산·판단 카드·미확인 처리·상품 가격 기준은 로컬 검수판과 동일하다. 데이터랩 카테고리와의 실제 연결은 후속 작업이며, 이 자료를 최신 운영 관측으로 설명하지 않는다.
