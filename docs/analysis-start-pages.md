# 분석 시작 화면

관리자 상위 메뉴의 업종분석과 지역분석은 각각 시작 화면을 연다. 저장된 최신 수집자료를 초기화 과정에서 읽더라도 상세 화면으로 자동 이동하지 않는다. B2B 계정의 기존 검색 진입은 유지한다.

## 업종분석

- 업종, 실제 저장된 검색어, 저장된 분석 대상 숙박기간으로 수집 회차를 찾는다. 서울근교처럼 행정구역 하나로 정할 수 없는 검색어도 그대로 표시한다.
- 자료 수집일은 회차의 `collectedAt`을 한국시간으로 표시한다. 수집 기록이 없어 파일 시각으로 대체된 이전 회차는 `collectedAtSource: filesystem`을 받아 수집일 확인 전과 저장 시점을 구분한다. 현재 시각으로 대체하지 않는다.
- 숙박기간은 `checkIn`부터 `bookingRangeDays`일간의 숙박일이다. 예를 들어 9월 21일부터 31일이면 10월 21일까지다. 서로 다른 기간의 회차를 임의로 합산하거나 선택 기간만 잘라 분석한 것처럼 표시하지 않는다.
- 분석 보기 또는 이어보기를 눌러야 상세 시장 브리핑으로 진입한다. 이어보기에는 해당 브라우저에서 같은 계정으로 직접 연 회차만 저장한다.
- 자료가 없으면 수집 화면 이동을 안내한다. 화면 이동 자체로 수집을 실행하지 않는다.
- 분석 요청 중 메뉴나 필터가 바뀌면 늦게 도착한 응답이 상세 화면을 강제로 열지 않는다.

## 지역분석

- 지역 마스터에서 현재 사용 가능한 행정구역을 검색한다. 경남 고성과 강원 고성처럼 동명 지역은 시·도까지 구분한다.
- 시작 화면의 검색/선택은 임시 선택이며, 지역 분석 보기를 눌러야 공통 선택 지역에 적용한다.
- 새 분석은 지역 현황으로 진입한다. 이전 분석 이어보기는 마지막으로 직접 선택한 지역과 마지막 지역 상세 메뉴로 돌아간다.
- 상세 메뉴는 지역 현황, 지역 지도, 수요 전망, 지역 비교, 자료·출처의 5개를 유지한다. 시작 화면은 상위 메뉴 목적지이며 여섯 번째 상세 메뉴가 아니다.
- 저장된 숙박 수집 횟수와 수집일은 정확히 같은 지역으로 연결되는 회차만 사용한다. 관광 자료의 개별 갱신일은 자료·출처에서 확인한다.
- 상위 메뉴로 돌아가도 선택 지역을 지우지 않는다. 상세 메뉴 이동, 지역 DB 왕복, 브라우저 뒤로/앞으로에서도 같은 지역을 유지한다.

## 확인

`npm run test:analysis-home`은 상위/모바일 진입, 명시적 열기, 늦은 응답, 날짜, 자료 없음, 계정별 이어보기, 지역 임시 선택과 동명 지역 구분을 검사한다. 기존 `test:navigation`, `test:region-analysis`, `test:dictionary-state`, `test:dictionary-demand`와 함께 실행한다. 실제 브라우저에서 데스크톱 및 모바일 크기의 표시도 확인한다.
