# 업종분석 — 플레이스 1~20위 관측

## 이번 개발 범위

사용자 결정(2026-10-11): 네이버 플레이스 검색 1~20위를 초기 분석 표본으로 사용한다. 업종·실제 소재지·숙박월을 선택해 저장 자료를 비교하는 UI와 분석 API를 개발한다. 규모별 분류와 성과 상/중/하 등급은 보류한다. 규모 구간을 향후 정의할 때 업종별 판매 단위(객실, 독립동, 캠핑 사이트)를 구분한다. 남해안 지역 지표에 사천시를 포함한다.

순위는 업체 성과등급이 아니다. 화면의 표본은 관측 기간에 1~20위에 포함된 업체이며 순위 변동과 여러 검색어 때문에 월간 고유 업체 수는 20개를 넘을 수 있다. 상위 검색 결과 표본이므로 지역 전체 업체를 대표하는 통계나 시장 규모로 표시하지 않는다.

## 지표와 자료 기준

- 업체는 고유번호로 식별하고 같은 업종·숙박일에서 중복 집계하지 않는다.
- 복합시설은 해당 업종 운영 업체군에 각각 포함한다. 다른 업종의 합계를 다시 더해 전체 매출을 만들지 않는다.
- 지역은 실제 소재지 또는 검수한 지역 수정값으로 정한다. 검색어의 지명을 실제 소재지로 간주하지 않는다.
- 객실 기준은 기존 월간 통합 계산의 관리자 검수값 / 고정 최대 관측값 우선순위를 사용한다. 현재 기준으로 과거 저장 자료를 재계산한 값이라는 점을 유지한다.
- 공개예약과 타채널 추정을 나눠 표시한다. 공유 데이유즈 제외 등 기존 월간 계산의 유효성 검사를 그대로 적용한다.
- 오류·차단·미확인은 정상 0과 구분한다. 유효 날짜만 예약률 분모에 포함하고 확보 일수와 미확인 일수를 함께 표시한다.
- 기본 예약률은 날짜 안에서 업체별 예약률을 동일 비중으로 평균하고, 관측 날짜끼리 다시 동일 비중으로 평균한다. 매출은 유효 날짜의 소계이며 월 전체 실적으로 확대하지 않는다.
- 업종 간 비교는 공통 지역과 비교 가능한 관측 날짜를 구분하고 지역별 비중을 동일하게 적용한다. 비교 조건이 부족하면 수치와 순위를 억지로 생성하지 않는다.
- 예약 시점은 실제 결제/예약 접수 시점이 아니라 마지막 유효 관측 시점이다. 과거 관측이 유지되는 경우 관측 지연을 표시한다.

## 지역 지표

사천은 현재 지역 마스터의 `kr_gyeongnam_sacheon`(사천시, 48240)을 사용한다. 과거 사천군 항목을 선택하지 않는다. 저장된 관광·검색·KOSIS 지표만 참고 자료로 조회하고, 자료가 없으면 미확인으로 표시한다. 연간 인구·산업 통계를 월간 값으로 바꾸거나 상대 검색지수를 지역 간 합산하지 않는다.

## 정기수집 계획 보관

정기수집 구성은 메모리에 별도 기록했다. 13개 후보 거점(포천·가평·홍천·양양·태안·제천·무주·여수·경주·청도·산청·서귀포·사천)과 가까운 숙박일 매일 / 먼 숙박일 주 2회 등의 주기는 검토안이다. 이번 변경은 수집 실행, 일정 등록·재활성화, 보호 해제, 운영 배포를 수행하지 않는다.

## API와 검증

관리자 GET `/api/industry-analysis/options`와 `/api/industry-analysis?industry=glamping&region=all&month=YYYY-MM`을 제공한다. 옵션과 필터 조작은 수집을 실행하지 않는다. 기존 개별 회차 분석은 원본 자료 확인 경로로 유지한다.

처음에는 보존된 순위 근거가 있는 최신 월을 선택한다. 공통 월간 계산의 내부 `industry` 범위로 현재 객실 검수값을 반영하며, 외부 월간 리포트 API의 허용 유형은 변경하지 않는다. 월·관측 기준일별 source 읽기는 최대 2개, 30초 동안 메모리에서 재사용한다.

검증은 순위 20/21 경계, 중복 업체, 복합업종, 실제 주소지, 불완전 재고, 정상 0, 비교 기간·지역, 권한과 외부 통신 금지, PC/모바일 다크·라이트 UI를 대상으로 한다. 검수용 모의 자료는 실제 운영 수치와 구분한다.

2026-10-11 로컬 검증 완료: 업종/화면/공통 자료 경로 테스트 40개, 전체 서버 HTTP 통합, 기존 업종 홈·분석 탐색, B2B 탐색 120항목 및 `check` 통과. HTTP 통합은 외부 fetch를 금지한 별도 모의 저장소에서 실행했고 업체 원본과 예약 이력이 바뀌지 않은 것을 확인했다. PC 다크·라이트와 390px 모바일에서 시각 검수했으며 가로 넘침과 브라우저 오류가 없었다. 운영 배포는 아직 수행하지 않았다.
