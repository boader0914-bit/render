# 경남글램핑 저장 자료 비교 계산

로컬 검토용 과거 원본에서 파생 자료를 만드는 읽기 전용 어댑터다. 데이터랩·인사이트 운영 API, 정기수집, 워커, 가격 변경, 쿠폰 발급과 연결하지 않는다.

## 재현

저장소 루트에서 다음과 같이 실행한다. 출력은 원본 폴더 밖의 **새 파일**이어야 한다. 기존 출력·원본·발행본을 덮어쓰지 않는다.

```powershell
node customer-portal/analysis/keyword-comparison/build-saved-comparison.cjs INPUT_ARCHIVE_ROOT NEW_OUTPUT_JSON
```

`INPUT_ARCHIVE_ROOT` 아래에는 `outputs/`, `company_master/companies.json`이 있어야 한다. 어댑터는 입력 안으로 출력하거나 입력 밖의 참조를 읽는 것을 거부한다. 읽은 원본의 SHA-256을 전후 비교하며 최종 JSON에 근거를 남긴다.

## 범위와 계산

- 폴더 접두사 대신 manifest의 정확한 `keyword=경남글램핑`으로 선택한다. 과거 정확 키워드 회차는 객실 최대관측 근거에만 사용하고 화면 비교는 9/20·21·22의 상위 20개 회차로 제한한다.
- 업체×상세종류 기준 외부 JSON을 우선하고 외부 본문이 없을 때만 CSV 인라인을 보완한다. 같은 상품×날짜 참조는 합산하지 않으며 상충하는 중복은 중단한다.
- canonical 업체 ID는 보존된 중앙 회사 목록에서 placeId로 유일하게 매핑한다. 미확인은 `mapping_unverified`와 별도 `place:` 로컬 키로 표시한다.
- 월명은 사용자·보존 DB 검수 16실을 우선한다. 9/26 스위트의 7실→6실 상품 보정도 기존 재고 계산기에 전달한다. 다른 업체도 활성 DB 검수값이 있으면 우선하고 없으면 정확 키워드의 최대관측 추정으로 경고한다.
- `scripts/inventory_estimation.cjs`의 기존 읽기 모델을 호출해 공유 데이유즈·런치/디너 재사용·상품별 최대관측 근거를 적용한다. 데이터랩 계산기를 수정하지 않는다.
- 최대관측 객실 기준은 같은 회차·날짜의 관측 객실 합계 최대이고, 상품별 최대는 상품 부족분 계산 근거로 별도 전달한다. 서로 다른 시점의 신규·종료 상품을 무조건 더해 객실 총량을 만들지 않는다.
- 9/20 구형 본문은 개별 관측 플래그가 없어 수량을 미확인으로 유지한다. 양의 공개 표시가격은 수량과 독립적으로 참고한다. 오류 0을 정상 0으로 만들지 않는다.
- 기준 객실수와 수량이 충돌하거나 공유 데이유즈가 불완전하면 해당 업체·일을 예약률 분자·분모에서 제외한다. 유효한 0실은 포함한다.
- 공개예약·타채널 추정은 분리하고, 예약률은 같은 유효 행의 예약 합계 / 공급 합계다. 원자 가격은 숙박 상품×날짜의 양의 표시가격이다. 가격 중앙값은 날짜별 중앙값들의 중앙값이 아니다.
- 증감은 같은 업체·숙박일·상품구성·객실 기준 버전의 두 유효 회차만 비교한다. 이전 회차는 실제 manifest 시각이 현재보다 앞서야 한다. 음수도 유지한다.
- 순증감은 취소·재예약·채널 재고 변경을 포함할 수 있다. 실제 예약 리드타임, 신규 예약 건수, 쿠폰 효과, 실제 결제매출로 표시하지 않는다.

## ESM 읽기 모델

`compare.mjs`는 외부 통신·파일 접근 없이 동작하는 순수 모듈이다.

```js
import { computeComparison } from './compare.mjs';
const view = computeComparison(snapshot, {
  runId: 'gyeongnam_glamping_20260922_140041',
  previousRunId: 'gyeongnam_glamping_20260921_140004',
  start: '2026-09-22', end: '2026-10-20',
  cohort: 'latest', dayFilter: 'all'
});
```

`cohort=latest`는 마지막 회차의 20곳을 고정한다. `cohort=run`은 선택 회차의 상위 20곳이다. 고정 표본의 업체가 이전 회차에 없으면 기대 업체·일에는 남기고 관측 공백으로 표시한다. 표본에 월명이 포함되는지 결과에 명시한다.

요일은 `all`, `weekday`(월~목), `friday`, `saturday`, `sunday`다. 공휴일 달력을 연결하지 않았으므로 월~목을 일반 비연휴 평일로 표현하지 않는다.

반환은 `selection`, `owner`, `benchmark`, `companies`, `daily`, `changes`, `cards`, `quality`다. 판단 카드는 근거와 검토 행동을 설명하며 모두 `reference_only` 또는 `hold`다. 할인율·자동 실행·매출 효과를 확정하지 않는다.
