# 방막기 추정 표시

- 인사이트의 화면 표시만 변경한다. DataLab 코드·DB·설정·배포 및 원본·매출 계산을 변경하지 않는다.
- 캘린더는 정상 관측에서 방막기 추정이 1실 이상인 날에만 보라색 수량과 방막기 추정매출을 표시한다. 합계 금액은 기존 값을 그대로 표시한다.
- 정상 0실은 캘린더 방막기 표시를 생략한다. 미수집·부분 응답·객실 수 충돌 및 미확인 가격은 0으로 바꾸지 않는다.
- 그래프의 공개 예약은 기존 녹색 선을 유지하고, 방막기 추정은 해당 날짜에만 보라색 막대를 그린다. 미확인은 ×로 표시하며 선으로 연결하지 않는다.
- 관측일별 비교에서도 보라색 막대를 사용한다. 기존 고정 숙박일 비교 및 증감 계산은 유지한다.
- 합계 카드와 수치 검토용 표는 기존 수치를 유지한다. 0 생략은 캘린더와 그래프의 표시 규칙이다.

검증: 정상 0·양수·누락·부분 응답·객실 충돌·가격 미확인, 입력 자료 불변, 기존 증감 계산, 모드 전환 및 수집 요청 분리. `node --test scripts/test_insight_connection.cjs customer-portal/test/*.test.cjs`.
