# 홈: 등록 업체와 최근 지역 분석

## 범위

요청한 1번 홈만 개선했다. 고객용 업체 상세, 경쟁업체 상세, 지역분석 본문과 리포트는 이번 변경 대상이 아니다. DataLab 코드·DB·설정·수집워커를 변경하지 않는다. 운영 배포는 하지 않았다.

## 동작

- 초기 로그인 응답으로 업체명·주소·객실 총량·최근 관측일을 즉시 표시한다. 회사 연결 누락은 미등록으로 바꾸지 않고 연결 확인 안내를 남긴다.
- 등록 완료, 연결 확인 대기, 업체 미등록, 매장 준비 중을 구분한다. 미등록 고객은 등록 버튼을, 준비 중 고객은 관심지역과 매장 등록 경로를 먼저 제공한다.
- 내 업체가 여러 곳이면 선택할 수 있다. 회사번호로 정확히 연결하며 업체 변경 후 이전 요청의 늦은 응답을 적용하지 않는다.
- 기존 GET `/reports/briefing?ownId=...`를 읽어 예약·매출과 지역 요약을 채운다. 미등록·관심지역 없음 상태에서는 브리핑도 조회하지 않는다. 홈에서 수집·지역 갱신 POST는 실행하지 않는다.
- 브리핑에서 더 최신 객실 수가 오면 초기 응답의 객실 수 대신 표시하고 근거 라벨을 최신 업체DB 기준으로 바꾼다. 읽기 시각을 관측일로 표시하지 않는다.
- 활성 내 업체의 정확한 소재지를 먼저 선택한다. 소재지가 없으면 등록된 활성 관심지역 순서로 선택한다. 연결 대기 업체에는 소재지 권한을 임의 부여하지 않는다.
- 방문자·체류·소비·검색 관심의 마지막 확보값과 각 실제 기준월, 전월 변화를 간단히 표시한다. 미확인은 0으로 바꾸지 않는다. 지수 차이는 p, 비율 변화는 %로 표시한다.
- 업체 기본정보는 조회 오류에도 남는다. 읽기 캐시는 60초이며 명시적 다시 확인은 새로 읽는다. 로그인·로그아웃·세션 만료·등록 변경 때 캐시를 초기화한다.
- 발행 리포트 목록 API는 없으므로 최근 발행일을 만들지 않고 `리포트 보기` 링크를 제공한다.

## 검증

- 홈 렌더링·정상 0/미확인·지역 선택·XSS·새 객실 총량 반영·비동기 결과 교체·읽기 실패·기존 고객 기능을 자동 검증했다.
- 실제 운영과 분리된 가상 자료로 PC 1280px, 모바일 390px, 밝은/어두운 화면을 확인했다. 등록 버튼 이동, 준비 중, 연결 대기와 조회 오류 상태도 확인했다.
- 화면 예시는 `C:/Users/User/.codex/visualizations/2026/10/05/insight-home/`에 있다. 예시 수치는 운영 자료가 아니다.
- 운영 서버 반영과 실제 고객 자료 검수는 별도 단계다.
