# 내 매장 메뉴에서 업체 DB 자동 조회

## 변경

- 기존에는 내 매장 메뉴가 등록 카드만 보여 주고, 업체 자료 보기 버튼을 눌러야 DB의 A~D 자료를 조회했다.
- 등록 업체가 연결돼 있으면 내 매장 메뉴 진입 시 기존 업체 DB 조회를 실행하여 객실·상품, 예약채널, 운영관측, 누적이력을 표시한다.

- 업체가 없으면 등록 화면, 연결된 업체 레코드가 없으면 연결 확인 안내를 유지한다. 연결 확인 대기 상태를 임의 승인하지 않는다.
- 30일 매출 수집은 별도 버튼이며 화면 조회나 매장 선택으로 수집 요청을 하지 않는다.
