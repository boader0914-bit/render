# 인사이트 고객 화면 개선 — 2026-10-04

## 범위

`customer-portal/`만 변경한다. 데이터랩 코드·DB·설정·수집워커는 수정하거나 배포하지 않는다. 기존 고객 권한으로 허용된 GET 자료를 읽으며, 화면 조회나 보고서 작성에서 수집 POST를 호출하지 않는다.

## 구현

- 객실 수 충돌·부분 응답·누락은 표/캘린더/날짜 목록/상단 합계에서 미확인으로 표시한다. 정상 0과 구분하며 저장값은 변경하지 않는다.
- 네이버/타채널·전화 및 만원 단위를 맞췄다. 전화예약의 추가 검증 안내는 넣지 않았다.
- 홈은 내 매장 예약·매출·예약률과 다음 행동, 경쟁 분석은 공통 숙박일·관측일의 예약률/평균 판매금액/매출 비교를 먼저 표시한다. 비교가 7일 미만이면 우열 판단을 보류한다.
- 업체 상세는 최근 운영 관측을 먼저 배치하고 기본정보·예약 채널을 접었다. 캘린더/그래프/날짜 목록/표로 보기 방식을 정리했다. 기존 개인 메모·검수 요청 폼은 유지한다.
- 지역 분석 상단에 방문자·소비·검색 관심의 최신 확보월과 전월/전년 비교를 표시한다. 서로 다른 확보월을 같은 시점으로 단정하지 않는다.
- 로그인 만료 시 기존 고객 화면과 메모리 캐시를 지우고 재로그인 안내를 표시한다. 관리자/고객별 허용된 해시 경로만 sessionStorage에 저장하며 로그인 후 한 번 복귀한다. 토큰·비밀번호를 저장하지 않는다.
- 브리핑/지역/업체 자료 GET은 화면 내 60초 메모리 재사용 및 동시 요청 중복 방지를 사용한다. 명시적 다시 확인은 새 조회이며 로그인 만료/로그아웃 때 지운다.

## 주간·월간 보고서

기존 업체DB의 현재·과거 숙박일 자료로 계산한다. 같은 업체 ID·숙박일은 한 번만 사용하고 가장 최근 관측을 우선한다. 최근 오류를 이전 정상 관측으로 감추지 않는다. 객실 수가 맞지 않는 날은 예약률에서 제외한다. 정상 수량일·금액 확보일을 구분하고 가격이 불완전하면 전체 금액 산출을 보류한다.

현재 상황/주간 7일/숙박월을 선택할 수 있으며 종료된 기간과 진행 중인 기간을 표시한다. 지역 배경은 선택 기간 종료월(현재 월이면 직전 마감월)을 끝으로 기존 12개월 자료를 읽는다. 현재 DB 검수값이 반영된 최신 저장 자료 기준이며 과거 특정 관측마감일을 재현하는 기능은 아니다.

인쇄/PDF 저장과 독립 HTML 파일 저장을 제공한다. 파일은 확인 시점의 검토 내용을 고정하며 스크립트·외부 요청 없이 열 수 있다. **서버 발행본 영구 보관·공유·자동 발행은 구현하지 않았다.** 현재 연결 API에는 고객별 발행본 저장 계약이 없으므로 파일 보관을 서버 발행으로 표시하지 않는다.

## 검증 상태

- 기존 연결/권한/수집 제한 검증 및 신규 기간 집계·세션 복귀·오류 표시 검증 69개 통과.
- 가상 자료만 사용하는 로컬 HTTP 검수 화면에서 홈/경쟁/지역/주간·월간 보고서/업체 상세와 390px 모바일 다크 날짜 목록을 확인했다.
- 월간 PDF 5쪽을 이미지로 렌더링해 확인했다. 본문 누락·글자 겹침 없음. HTML 다운로드 파일의 기간·본문·스크립트 없음·외부 통신 차단 정책을 확인했다.
- 운영 서버에는 아직 배포하지 않았다. 운영 세션이 만료되어 실제 운영 자료를 새 화면으로 확인하지 않았다.
