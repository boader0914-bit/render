# 인사이트 합산 예약·매출 표시

2026-10-04. 승인된 캘린더·그래프 시안을 인사이트 프런트엔드에 적용한다. DataLab 코드·DB·운영 설정 및 수집워커는 변경하거나 배포하지 않는다.

- 제목은 ‘선택일 추정 예약·매출’, ‘날짜별 추정 예약·매출’이며 카드에는 ‘예약’, ‘매출’을 표시한다.
- 예약 합계는 정상 자료의 publicBookings + phoneBookings다. 매출 카드에는 기존 estimatedRevenue를 그대로 사용한다. 기존 합계에 phoneRevenue를 다시 더하지 않는다.
- 네이버 관측은 녹색, 방막기에 대응하는 타채널·전화 추정은 보라색으로 표시한다. 전화예약 검증 요청이나 확인 완료 표현은 추가하지 않는다. 특정 플랫폼에 매출을 임의 배분하지 않는다.
- 예약수량 및 매출의 두 그래프는 네이버와 타채널·전화의 막대를 쌓고 그 합계를 선으로 연결한다. 오류·누락은 선을 끊고 ×로 표시한다. 정상 0은 합계선의 0으로 유지하며 보라색 막대는 생략한다.
- 그래프의 날짜, 캘린더의 날짜, 날짜 입력에서 같은 선택일 합계를 조회한다. ‘기간 합계’로 기존 기간 수치를 볼 수 있다. 선택·전환은 로컬 표시만 바꾸며 API 호출·수집 실행·데이터 수정을 하지 않는다.
- 초기 선택일은 자료에 오늘(KST)이 있으면 오늘, 없으면 첫 정상 관측일이다. 선택한 날짜에 자료가 없으면 미확인으로 표시한다.
- 기본/캘린더/그래프/표 전환과 기존 A/B/D 정보 및 수정 요청 폼을 유지한다. PC는 두 그래프를 나란히, 모바일은 세로로 배치한다.

검증: 합계 16실=5+11, 490.4만원=151.5+338.9의 막대 높이·합계선, 정상 0과 오류·가격 누락 구분, 입력 자료 불변, 날짜 선택·모드 전환의 무요청 동작, 기존 고정 숙박월 비교 및 수정 폼 보존.

검증 명령: `node --test scripts/test_insight_connection.cjs customer-portal/test/*.test.cjs`.
